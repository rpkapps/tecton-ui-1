## Usage

```tsx
import { CircularProgress } from "@tecton/react/tecton/circular-progress"
```

```tsx
<CircularProgress aria-label="Resampling" value={64} showValue />
```

<Callout>
  [Progress](/docs/components/progress) is a linear bar and [Spinner](/docs/components/spinner) is an icon. Tecton's circular progress with a value label is a separate component.
</Callout>

## Sizes

Use the `size` prop from 16 px (`xs`) to 96 px (`xl`). Stroke width and label size scale with it.

## Value label

Set `showValue` to render the formatted value in the centre, or pass children for custom content. `minValue` and `maxValue` set the range; `formatOptions` takes `Intl.NumberFormat` options.

## API Reference

### CircularProgress

An accessible progress bar rendered as a ring. Accepts `value`, `minValue`, `maxValue`, `isIndeterminate`, `formatOptions` and `valueLabel`.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `size` | `"xs" \| "sm" \| "md" \| "lg" \| "xl"` | "md" | Diameter 16 / 24 / 40 / 64 / 96 px. |
| `color` | `"primary" \| "foreground" \| "success" \| "warning" \| "error" \| "info"` | "primary" | Ring colour. |
| `showValue` | `boolean` | false | Show the formatted value in the centre. |
| `children` | `ReactNode` | - | Custom centre content (overrides `showValue`). |
| `aria-label` | `string` | - | Accessible name (required without a visible label). |
