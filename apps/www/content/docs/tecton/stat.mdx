## Usage

```tsx
import {
  Stat,
  StatLabel,
  StatValue,
  StatDelta,
  StatHelp,
  StatGroup,
} from "@tecton/react/tecton/stat"
```

```tsx
<Stat>
  <StatLabel>Cost per barrel</StatLabel>
  <StatValue unit="USD">16.9</StatValue>
  <StatDelta trend="down" tone="positive">-8% vs. Alternative A</StatDelta>
  <StatHelp>Base case, P50 volumes</StatHelp>
</Stat>
```

<Callout>
  The IBM Plex Mono value with a sans unit is a Tecton typography rule that no shadcn component carries; `Stat` is the building block for the FDA and Well Design cards.
</Callout>

## Delta

Use `StatDelta` with `trend` for an up, down or flat indicator. The colour follows `tone`, which says whether the change is good news rather than which way it went: it defaults to the trend's (up is `positive`, down `negative`, flat `neutral`), so set it where down is good news — cost, CAPEX, downtime, risk.

```tsx
<StatDelta trend="down" tone="positive">-8% vs. Alternative A</StatDelta>
```

## Usage guidelines

### Use it when

- A card, a panel or a header reports one measured number: cost per barrel, NPV, drilling days.
- The number wants a unit and a change against a baseline or a previous period.
- Several KPIs sit side by side and their digits have to align: that is `StatGroup`.

### Not for

- a word that names a status or a category: use [Badge](/docs/components/badge)
- a value read against a fixed scale with named bands: use [Meter](/docs/tecton/meter)
- a series compared over time or across categories: use [ChartContainer](/docs/components/chart)

### Do

<DoList>

<Do>

Compose the parts inside `Stat`: `StatLabel`, `StatValue` with its `unit`, `StatDelta`, `StatHelp`.

</Do>

<Do>

Scale the value with `size="sm" | "md" | "lg"` (14 / 20 / 28 px) and place the block with `align="start" | "center" | "end"`.

</Do>

<Do>

Say which way the number moved with `StatDelta`'s `trend="up" | "down" | "flat"` (the icon), and whether that is good news with `tone="positive" | "negative" | "neutral"` (the colour). `tone` follows the trend unless you set it: set `tone="positive"` on a falling cost, downtime or risk.

</Do>

<Do>

Pass the unit to `StatValue`'s `unit` prop rather than writing it into the text, so it renders in the sans face at `0.6em`.

</Do>

<Do>

Lay a row of KPIs out with `StatGroup`, the responsive `auto-fit` grid; `className` on it is for width and placement only.

</Do>

</DoList>

### Don't

<Dont severity="CRITICAL" title="A KPI as a heading and a coloured span">

<Wrong>

```tsx
<div className="flex flex-col gap-0.5">
  <span className="text-xs text-gray-500">NPV</span>
  <h3 className="text-2xl font-semibold">1 240 MUSD</h3>
  <span className="text-sm text-green-600">+11%</span>
</div>
```

</Wrong>

<Correct>

```tsx
<Stat size="lg">
  <StatLabel>NPV</StatLabel>
  <StatValue unit="MUSD">1 240</StatValue>
  <StatDelta trend="up">+11%</StatDelta>
</Stat>
```

</Correct>

`text-gray-500` and `text-green-600` are stock Tailwind that the reset palette emits no CSS for, so the label and the change both render in the body colour, and the value loses the `font-mono tabular-nums` that stops a column of KPIs jittering as the digits change.

</Dont>

<Dont severity="HIGH" title="Colouring the delta by hand instead of with trend">

<Wrong>

```tsx
<Stat>
  <StatLabel>CAPEX</StatLabel>
  <StatValue unit="MUSD">312</StatValue>
  <StatDelta className="text-red-600">-4%</StatDelta>
</Stat>
```

</Wrong>

<Correct>

```tsx
<Stat>
  <StatLabel>CAPEX</StatLabel>
  <StatValue unit="MUSD">312</StatValue>
  <StatDelta trend="down" tone="positive">-4%</StatDelta>
</Stat>
```

</Correct>

`trend` picks the `TrendingUp` / `TrendingDown` / `Minus` icon and `tone` the `text-success` / `text-destructive` / `text-muted-foreground` colour — a CAPEX cut points down and reads as good news — so the hand-coloured version keeps the default flat dash while `cn` drops `text-muted-foreground` for a `text-red-600` that emits nothing.

</Dont>

<Dont severity="MEDIUM" title="The unit written into the value">

<Wrong>

```tsx
<Stat>
  <StatLabel>Recoverable volume</StatLabel>
  <StatValue>42.1 MSm³</StatValue>
</Stat>
```

</Wrong>

<Correct>

```tsx
<Stat>
  <StatLabel>Recoverable volume</StatLabel>
  <StatValue unit="MSm³">42.1</StatValue>
</Stat>
```

</Correct>

The `unit` slot renders `font-sans text-[0.6em] text-muted-foreground` beside the number; inside the children the unit is set in IBM Plex Mono at the full value size and counted by `tabular-nums`, so it reads as part of the figure and the columns of a `StatGroup` stop lining up.

</Dont>

## API Reference

### Stat

Container that sets the value size and alignment.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `size` | `"sm" \| "md" \| "lg"` | "md" | Value font size 14 / 20 / 28 px. |
| `align` | `"start" \| "center" \| "end"` | "start" | Alignment of the parts. |

### StatValue

The value in the mono font with tabular numbers.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `unit` | `ReactNode` | - | Unit rendered after the value. |

### StatDelta

Trend indicator with icon. It sets `data-trend` and `data-tone`.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `trend` | `"up" \| "down" \| "flat"` | "flat" | Which way the number moved; picks the icon. |
| `tone` | `"positive" \| "negative" \| "neutral"` | from `trend` | Whether the move is good or bad; picks the colour. Defaults to the trend's (up `positive`, down `negative`, flat `neutral`). |

### StatLabel, StatHelp, StatGroup

Plain styled elements.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `className` | `string` | - |  |
