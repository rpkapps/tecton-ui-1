## With label

A labelled divider is a flex row with a `Separator` on each side of the text. The row itself gets no `role="separator"`: a separator's content is presentational, so assistive technology would drop the label. Wrap the two rules in `aria-hidden` elements instead; they are decorative, and the label is read as ordinary text.

## Usage guidelines

### Use it when

- Two groups of content need a visible break that no heading or spacing gives them.
- A toolbar or a meta row needs a vertical rule between clusters of controls.
- A labelled divider: a `role="separator"` flex row with a `Separator` on each side of the text.

### Not for

- a divider between the rows of a list: use [ItemSeparator](/docs/components/item)
- the rule under a panel title: use [PanelHeader](/docs/tecton/panel)
- the borders between the regions of the application frame: use [AppShell](/docs/tecton/app-shell)

### Do

<DoList>

<Do>

Pick the weight with `emphasis="subtle" | "default" | "strong"`; these are the three Tecton divider levels.

</Do>

<Do>

Set the axis with `orientation="vertical"`, and let the parent flex row give it height — it carries `self-stretch`.

</Do>

<Do>

Keep `className` to layout (`flex-1`, `my-2`): the variant owns colour and thickness.

</Do>

<Do>

Reach for a component's own divider first — `ItemSeparator` in an `ItemGroup`, `border-b` on a `CardHeader`, `PanelHeader`'s built-in rule.

</Do>

</DoList>

### Don't

<Dont severity="HIGH" title="A hand-drawn rule with a stock Tailwind colour">

<Wrong>

```tsx
<div className="flex flex-col gap-4">
  <p>Alternative A</p>
  <div className="border-t border-gray-200" />
  <p>Alternative B</p>
</div>
```

</Wrong>

<Correct>

```tsx
<div className="flex flex-col gap-4">
  <p>Alternative A</p>
  <Separator emphasis="subtle" />
  <p>Alternative B</p>
</div>
```

</Correct>

Tecton resets Tailwind's stock palette to `initial`, so `border-gray-200` generates no CSS and the rule is invisible in both modes; `Separator` also carries `role="separator"`, which a bare `div` does not.

</Dont>

<Dont severity="MEDIUM" title="Recolouring the rule instead of raising its emphasis">

<Wrong>

```tsx
<Separator className="bg-zinc-300 dark:bg-zinc-700" />
```

</Wrong>

<Correct>

```tsx
<Separator emphasis="strong" />
```

</Correct>

The three emphases map to `--border-subtle`, `--border` and `--border-strong`, which already switch between modes; the stock `zinc` classes emit nothing, and `bg-zinc-300` overrides the colour the `emphasis` variant already owns.

</Dont>

<Dont severity="MEDIUM" title="A vertical rule with a hand-set height">

<Wrong>

```tsx
<div className="flex items-center gap-4">
  <span>Subtle</span>
  <Separator orientation="vertical" className="h-4 w-px bg-border" />
  <span>Strong</span>
</div>
```

</Wrong>

<Correct>

```tsx
<div className="flex h-8 items-center gap-4">
  <span>Subtle</span>
  <Separator orientation="vertical" />
  <span>Strong</span>
</div>
```

</Correct>

A vertical `Separator` is `w-px self-stretch`, so it takes its height from the flex row; `h-4` freezes it at one size instead, and `bg-border` overrides the colour the `emphasis` variant already owns.

</Dont>
