Components, Tecton components, icons and the theme are all imported from the package `@tecton/react`; nothing is installed per component. **Blocks** are the exception: they are starting points you copy into your application, so they come from a shadcn registry.

<Steps>

<Step>Install the package</Step>

`@tecton/react` is private: it is not on the public npm registry.

<TabsContent value="registry">

```bash
pnpm --filter @tecton/react publish --registry https://npm.example.com
```

```ini title=".npmrc (consuming project)"
@tecton:registry=https://npm.example.com
```

```bash
pnpm add @tecton/react
```

</TabsContent>

</Tabs>

Requirements: React 19, Tailwind CSS v4 (the package ships Tailwind sources, not compiled CSS), a bundler that resolves `package.json` `exports`, and TypeScript `"moduleResolution": "bundler"` (or `"node16"` / `"nodenext"`). The package is unbundled ESM with a `.d.ts` per module and keeps each file's `"use client"`, so it needs no transpiling.

<Step>Import the stylesheet</Step>

Import it once. It contains Tailwind, the shadcn runtime styles, the Tecton tokens and palette, and declares an `@source` for the package's own output:

```css title="src/styles/app.css"
@import "@tecton/react/globals.css";
```

Tailwind scans your project from its auto-detected root; add an `@source` after the import for sources outside it.

<Step>Set the mode</Step>

Tecton is dark-first: put the `dark` class on `<html>` (for example with `next-themes`, `attribute="class"`, `defaultTheme="dark"`). Without it you get the light theme. See [Theming](/docs/theming).

<Step>Mount `TectonProvider` when you need it</Step>

Mount [`TectonProvider`](/docs/tecton/provider) once at the root for a locale or right-to-left direction, client-side navigation of Tecton links (`navigate`, `useHref`), or a custom overlay container. Without it, components read left to right in the browser's locale, links do full page loads and overlays portal into `document.body`.

An application mounted inside another one (a Module Federation remote, an embedded widget) renders [`ThemeRoot`](/docs/tecton/theme-root) instead, which includes the provider; see [Micro-frontends](/docs/micro-frontends).

<Step>Use the components</Step>

```tsx
import { Badge } from "@tecton/react/components/badge"
import { Button } from "@tecton/react/components/button"
import { WellIcon } from "@tecton/react/icons"

export function Example() {
  return (
    <div className="flex items-center gap-2">
      <Button>
        <WellIcon data-icon="inline-start" /> New well
      </Button>
      <Badge variant="success">Active</Badge>
    </div>
  )
}
```

</Steps>

## Blocks

Blocks (dashboards, panels, forms, page states) are served as a shadcn registry named `@tecton`. The copied files import the components from `@tecton/react`, so install the package first.

```json title="components.json"
{
  "registries": {
    "@tecton": "https://<your-docs-host>/r/{name}.json"
  }
}
```

```bash
npx shadcn@latest add @tecton/dashboard-01
```

Every block on the [Blocks](/blocks) page shows its command. For a private host use `"@tecton": { "url": "…", "headers": { "Authorization": "Bearer ${TECTON_TOKEN}" } }`.
