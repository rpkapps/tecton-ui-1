## Usage

```tsx
import { CopyButton } from "@tecton/react/tecton/copy-button"
```

```tsx
<CopyButton value="34/10-A-12" />
```

## Labelled

Pass children for a labelled button; the size then defaults to `sm` instead of `icon-sm`. All `Button` variants are available.

<ComponentPreview name="copy-button-labelled" />

## Feedback

Use `onCopied` to react to a successful copy and `timeout` to control how long the check is shown.

## Errors

When the clipboard refuses the write (an insecure context, a denied permission, a browser without the Clipboard API) the button shows a cross in the destructive colour for `timeout` ms instead of the check, and `onError` receives the clipboard's error. Both outcomes are announced politely through one shared live region: "Copied" or "Copy failed". An icon-only button also takes that text as its accessible name for as long as the state lasts ("Copy" otherwise).

```tsx
<CopyButton value={wellId} onError={() => toast.error("Could not copy the well ID")} />
```

The button sets `data-copied="true"` or `data-error="true"` while the state is shown.

## Usage guidelines

### Use it when

- A value on screen is meant to be pasted elsewhere: an identifier, a URL, a snippet.
- The user needs the copy confirmed in place, without a toast or a dialog.
- The control sits next to the value, usually as a quiet icon button.

### Not for

- any action on a value other than copying it: use [Button](/docs/components/button)
- a confirmation that appears away from the control: use [toast](/docs/components/sonner)

### Do

<DoList>

<Do>

Pass the text as `value` and let the component own the press handler.

</Do>

<Do>

Leave it icon-only for a quiet affordance, or pass text `children` for a prominent labelled one.

</Do>

<Do>

Set weight with `variant` (it defaults to `ghost`) and hold time with `timeout`.

</Do>

<Do>

React to a successful copy with `onCopied`, not by wrapping the button in your own handler.

</Do>

<Do>

Let the component name itself: with no children it sets `aria-label` to "Copy", then "Copied".

</Do>

</DoList>

### Don't

<Dont severity="HIGH" title="A Button with a hand-written clipboard handler">

<Wrong>

```tsx
<Button variant="ghost" size="icon-sm" onPress={() => navigator.clipboard.writeText(well.id)}>
  <CopyIcon />
</Button>
```

</Wrong>

<Correct>

```tsx
<CopyButton value={well.id} />
```

</Correct>

The hand-rolled version drops everything the component adds: the copied state and check-mark swap, the `aria-label` that flips to "Copied", and the catch for a denied or insecure clipboard, which otherwise rejects unhandled.

</Dont>

<Dont severity="HIGH" title="An onPress handler passed to CopyButton">

<Wrong>

```tsx
<CopyButton value={well.id} onPress={() => track("copy")} />
```

</Wrong>

<Correct>

```tsx
<CopyButton value={well.id} onCopied={() => track("copy")} />
```

</Correct>

`CopyButton` omits `onPress` from its props and spreads the remaining props after its own, so an `onPress` you pass replaces the clipboard handler and the button quietly stops copying.

</Dont>

<Dont severity="HIGH" title="Supplying the icon as the child">

<Wrong>

```tsx
<CopyButton value={well.id}><CopyIcon /></CopyButton>
```

</Wrong>

<Correct>

```tsx
<CopyButton value={well.id} />
```

</Correct>

The component already renders `CopyIcon` or `CheckIcon` itself, so a child icon is drawn twice, switches the size default from `icon-sm` to `sm`, and suppresses the automatic accessible name because children are now present.

</Dont>

{/* guidelines:end */}

## API Reference

### CopyButton

The shadcn `Button` with clipboard behaviour; accepts all `Button` props except `onPress`.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `value` | `string` | - | Text written to the clipboard. |
| `timeout` | `number` | 2000 | Milliseconds the check (or the failure cross) is shown. |
| `onCopied` | `(value: string) => void` | - | Called after a successful copy. |
| `onError` | `(error: unknown) => void` | - | Called with the clipboard's error when the copy fails; the button then shows "Copy failed". |
| `variant` | `ButtonProps["variant"]` | "ghost" | Button variant. |
| `size` | `ButtonProps["size"]` | "icon-sm" \| "sm" | Defaults by presence of children. |
| `children` | `ReactNode` | - | Label. |
