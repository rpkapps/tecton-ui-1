## Usage

```tsx
import { CountBadge } from "@tecton/react/tecton/count-badge"
```

```tsx
<CountBadge count={4} color="destructive">
  <Button variant="outline" size="icon" aria-label="Notifications, 4 unread">
    <BellIcon />
  </Button>
</CountBadge>
```

The badge is hidden from assistive technology, so put the count in the child's accessible name. This is the design system's *Badge*; the library calls it `CountBadge` because [Badge](/docs/components/badge) is the static label.

## Colors

`color` takes Badge's `variant` names, so the same word means the same status on both.

<ComponentPreview name="count-badge-colors" />

## Dot

`variant="dot"` is a presence or status indicator without a number. `anchor` places the badge on any corner of its child. Corners follow the reading direction: `end` is the right side in a left-to-right layout and the left side in a right-to-left one.

<ComponentPreview name="count-badge-dot" />

## Max, zero and custom content

Counts above `max` render as `max+`. A count of `0` hides the badge unless `showZero` is set; `content` replaces the number.

## Usage guidelines

### Use it when

- A number belongs to an icon button, an avatar or a tab: unread messages, queued jobs, open comments.
- A presence or status dot belongs to an avatar or a tab: `variant="dot"`.
- The number decorates the control; it is not a label the user reads on its own.

### Not for

- a label with words in it, in the flow of the page: use [Badge](/docs/components/badge)
- a tag the user can select or remove: use [Chip](/docs/tecton/chip)
- a busy indicator on an icon button: use [Spinner](/docs/components/spinner)

### Do

<DoList>

<Do>

Wrap the control — `CountBadge` renders the positioned anchor and the badge, and the control stays its child.

</Do>

<Do>

Let the badge hide itself: `count={0}` renders nothing unless `showZero`, and `invisible` hides it while keeping the anchor.

</Do>

<Do>

Pick `color` — `default`, `secondary`, `destructive`, `success`, `warning`, `info`, the same names as Badge's `variant` — `anchor` (`top-end` … `bottom-start`) and `max` (counts above it render as `99+`).

</Do>

<Do>

Put the number in the control's accessible name — `aria-label="Messages, 4 unread"` — because the badge is decorative: it renders `aria-hidden`, so assistive tech never hears the number anywhere else.

</Do>

</DoList>

### Don't

<Dont severity="HIGH" title="Hiding the control along with the count">

<Wrong>

```tsx
{unread > 0 && (
  <CountBadge count={unread} color="destructive">
    <Button variant="outline" size="icon" aria-label="Messages">
      <MailIcon />
    </Button>
  </CountBadge>
)}
```

</Wrong>

<Correct>

```tsx
<CountBadge count={unread} color="destructive">
  <Button variant="outline" size="icon" aria-label={`Messages, ${unread} unread`}>
    <MailIcon />
  </Button>
</CountBadge>
```

</Correct>

`CountBadge` is the wrapper, not the badge, so guarding it removes the button from the page as well; the component already hides the badge itself when `count` is 0.

</Dont>

<Dont severity="HIGH" title="Building the count by hand">

<Wrong>

```tsx
<div className="relative inline-flex">
  <Button variant="outline" size="icon" aria-label="Notifications"><BellIcon /></Button>
  <span className="absolute -top-1 -right-1 rounded-full bg-red-500 px-1 text-white">{count}</span>
</div>
```

</Wrong>

<Correct>

```tsx
<CountBadge count={count} color="destructive">
  <Button variant="outline" size="icon" aria-label="Notifications">
    <BellIcon />
  </Button>
</CountBadge>
```

</Correct>

`red-500` is not a Tecton step, so the reset palette gives the pill no background at all, and the hand-built span has none of the `ring-2 ring-background` cut-out, the `max` cap or the zero handling.

</Dont>

<Dont severity="MEDIUM" title="Putting a count on a dot">

<Wrong>

```tsx
<CountBadge variant="dot" color="destructive" count={5}>
  <Avatar><AvatarFallback>JD</AvatarFallback></Avatar>
</CountBadge>
```

</Wrong>

<Correct>

```tsx
<CountBadge color="destructive" count={5}>
  <Avatar><AvatarFallback>JD</AvatarFallback></Avatar>
</CountBadge>
```

</Correct>

The dot variant is an 8 px circle that renders no children by design, so the number is dropped and only the dot appears.

</Dont>

{/* guidelines:end */}

## API Reference

### CountBadge

Wraps its child in a relatively positioned `span`; other props go to that `span`.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `count` | `number` | - | Number to display. |
| `max` | `number` | `99` | Counts above this render as `max+`. |
| `showZero` | `boolean` | `false` | Show the badge when `count` is 0. |
| `content` | `ReactNode` | - | Content instead of the count, e.g. "New". |
| `invisible` | `boolean` | `false` | Hide the badge, keep the child. |
| `color` | `"default" \| "secondary" \| "destructive" \| "success" \| "warning" \| "info"` | `"default"` | Badge colour. |
| `variant` | `"standard" \| "dot"` | `"standard"` | Number pill or 8 px dot. |
| `anchor` | `"top-end" \| "top-start" \| "bottom-end" \| "bottom-start"` | `"top-end"` | Corner of the child; `start` and `end` follow the reading direction. |
