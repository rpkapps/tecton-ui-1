These pages are the shadcn/ui documentation for the React Aria base, synced from upstream and adjusted for `@tecton/react` imports. The components themselves are byte-identical to what `npx shadcn@latest add <name>` produces with `--base aria --preset vega`; only the CSS variables differ.

<Callout title="Two ways to consume">
  Import from the package (`import { Button } from "@tecton/react/components/button"`) or copy the source into your project with the CLI command shown in each **Installation** section. Both give you the same component.
</Callout>
