---
title: Tecton components
description: "Components that exist only in the Tecton design system and have no shadcn counterpart."
---

Every component in [Components](/docs/components) is a shadcn/ui component in the Tecton style; the design system's extra variants (alert and badge status colours, text-field surfaces, separator emphasis) are documented on those pages. The components here are the patterns shadcn does not have. They follow the same conventions and are imported from `@tecton/react/tecton/<name>`.

| Component | Description |
| --- | --- |
| [Action Bar](/docs/tecton/action-bar) | Transient bar for a selection or unsaved changes, with collapsing actions. |
| [App Finder](/docs/tecton/app-finder) | Application switcher for the shell header. |
| [App Shell](/docs/tecton/app-shell) | Application frame: top bar with the global action cluster, sidebar, main area and aside. |
| [Background](/docs/tecton/background) | Decorative background effects from oil and gas imagery, themed in both modes. |
| [Canvas](/docs/tecton/canvas) | Full-bleed work surface with floating toolbars, legend and overlays. |
| [Chip](/docs/tecton/chip) | Selectable and removable tags in a group; static labels are Badges. |
| [Circular Progress](/docs/tecton/circular-progress) | Progress ring with value label or indeterminate spinner. |
| [Color Swatch](/docs/tecton/color-swatch) | Colour preview with optional label and value, optionally editable. |
| [Composer](/docs/tecton/composer) | Message box of a chat: send and stop, history, slash commands and removable context. |
| [Copy Button](/docs/tecton/copy-button) | Copies a value to the clipboard with check-mark feedback. |
| [Count Badge](/docs/tecton/count-badge) | Count or dot anchored to the corner of an avatar or icon button. |
| [Link](/docs/tecton/link) | Inline text link and button-styled link that navigate through the router. |
| [Meter](/docs/tecton/meter) | Segmented gauge for risk, complexity and confidence. |
| [Overflow](/docs/tecton/overflow) | Toolbar row that collapses labels, then items into a More menu, when narrow. |
| [Page Header](/docs/tecton/page-header) | Page title block with eyebrow, description, section tabs and actions. |
| [Panel](/docs/tecton/panel) | Titled application surface with scrolling body and pinned footer. |
| [Stat](/docs/tecton/stat) | KPI readout with mono value, unit and trend delta. |
| [Tecton Provider](/docs/tecton/provider) | The one provider an application mounts: locale, reading direction, client-side router and overlay container. |
| [Theme Root](/docs/tecton/theme-root) | Root of an independently deployed application: its theme scope and its overlay container. |
| [Tree View](/docs/tecton/tree-view) | Hierarchical tree with folder and item rows, states and adornments. |
