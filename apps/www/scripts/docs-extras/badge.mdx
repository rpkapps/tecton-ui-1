## Status colours

The Tecton style overlay adds `variant="success" | "warning" | "info"` next to `destructive`, and an `appearance="outline"` for a transparent badge with a coloured border and text. The interactive, selectable and removable variant of the badge is the Tecton [Chip](/docs/tecton/chip), which reuses the same `variant`, `appearance` and `size` props.

## Sizes

Use `size="default" | "md" | "lg"` (20 / 24 / 28 px); icons scale with the size.
