## Usage

```tsx
import {
  TextField,
  TextFieldLabel,
  TextFieldInput,
  TextFieldTextarea,
  TextFieldDescription,
  TextFieldError,
} from "@tecton/react/tecton/text-field"
```

```tsx
<TextField
  label="Well name"
  placeholder="34/10-A-12"
  description="Use the NPD well identifier."
  onChange={(value) => setName(value)}
/>
```

<Callout title="Variants and shadcn">
  The shadcn `Input` only knows one look, which is Tecton's *outlined* style. The *filled* and *text-only* variants cannot be expressed through CSS variables, so `TextField` wraps the unchanged `Input` / `Textarea` and adds them as classes. For plain shadcn forms use [Field](/docs/components/field) and [Input](/docs/components/input).
</Callout>

## Variants

Use the `variant` prop. `outlined` is the unchanged shadcn `Input`; `filled` adds a muted surface with a bottom border; `textOnly` keeps only the underline.

## API Reference

### TextField

React Aria [`TextField`](https://react-aria.adobe.com/TextField); accepts all its props (`value`, `onChange(value: string)`, `isDisabled`, `isRequired`, `validate`…).

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `variant` | `"outlined" \| "filled" \| "textOnly"` | "outlined" | Visual variant of the control. |
| `size` | `"md" \| "sm"` | "md" | Control height. |
| `label` | `ReactNode` | - | Renders a `TextFieldLabel`. |
| `description` | `ReactNode` | - | Renders a `TextFieldDescription`. |
| `errorMessage` | `ReactNode` | - | Renders a `TextFieldError` and sets `isInvalid`. |
| `placeholder` | `string` | - | Placeholder of the default control. |
| `multiline` | `boolean` | false | Render a `Textarea`. |
| `rows` | `number` | - | Rows of the textarea. |
| `children` | `ReactNode` | - | Custom control; replaces the default input. |

### TextFieldLabel

The shadcn `Label`, coloured on focus, error and disabled.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `className` | `string` | - |  |

### TextFieldInput

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `className` | `string` | - |  |

### TextFieldTextarea

The shadcn `Textarea` with the variant classes.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `className` | `string` | - |  |

### TextFieldDescription

| Prop | Type | Default | Description |
| --- | --- | --- | --- |

### TextFieldError

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `className` | `string` | - |  |
