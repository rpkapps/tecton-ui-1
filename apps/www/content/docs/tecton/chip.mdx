## Usage

```tsx
import { Chip, ChipGroup, ChipList } from "@tecton/react/tecton/chip"
```

```tsx
<ChipGroup aria-label="Horizons" onRemove={(values) => remove(values)}>
  <ChipList>
    <Chip value="balder" variant="info">Top Balder</Chip>
    <Chip value="sele" variant="info">Top Sele</Chip>
  </ChipList>
</ChipGroup>
```

A chip is the interactive [Badge](/docs/components/badge): same `variant`, `appearance` and `size`, same look. Use a Badge for a static label and a [Count Badge](/docs/tecton/count-badge) for a count on an icon.

The group is one tab stop; <Kbd>←</Kbd> <Kbd>→</Kbd> move between chips. With `onRemove`, every chip gets a remove button and <Kbd>Delete</Kbd> or <Kbd>Backspace</Kbd> removes the focused chip (or all selected chips, when it is selected). Render chips from data with `items` and a function child, as the demo does.

## Selectable

Set `selectionMode="single"` or `"multiple"` on the group and hold the selection in `value` / `onValueChange` (or `defaultValue`).

<ComponentPreview name="chip-selectable" />

## Variants

Every Badge colour, as a solid surface or with `appearance="outline"`. The default is `variant="secondary"`; sizes are `default`, `md` and `lg` (20 / 24 / 28 px), and icons marked `data-icon="inline-start"` scale with them.

## Usage guidelines

### Use it when

- The user toggles the label: active filters, selected facies, chosen horizons.
- The user removes the label: applied filters, recipients, keywords, attachments.
- The set is small enough that every chip is on screen at once.

### Not for

- a label that is never selected or removed: use [Badge](/docs/components/badge)
- a count or dot pinned to the corner of an icon or avatar: use [CountBadge](/docs/tecton/count-badge)
- a confirmation that a tag was removed: use [toast](/docs/components/sonner)

### Do

<DoList>

<Do>

Compose `ChipGroup > ChipList > Chip` and name the group with `aria-label`; the list is the `role="grid"` it names.

</Do>

<Do>

Give every `Chip` a `value`: it is what `value`, `onValueChange` and `onRemove` hold. Add a `label` when the children are not plain text.

</Do>

<Do>

Turn on selection with `selectionMode="single" | "multiple"` and `value` / `onValueChange` (or `defaultValue`) on the group; `disabled` on a chip or on the whole group.

</Do>

<Do>

Turn on removal with `onRemove` on the group: every chip gets its remove button, and Delete or Backspace removes the focused one.

</Do>

<Do>

Take the look from the Badge axes: `variant`, `appearance="outline"`, `size`. `className` is for layout only; style state with `data-selected`, `data-disabled`, `:hover` and `:focus-visible`.

</Do>

<Do>

Use a `Chip` only to select or remove a value; actions are a `Button`, destinations a `Link`, even when small.

</Do>

<Do>

Use at most two or three chip colours in one `ChipGroup`, each with one fixed meaning; beyond that, distinguish with text.

</Do>

<Do>

Give the `ComboboxChipsInput` a placeholder naming what can be added ("Add wells…").

</Do>

<Do>

Selected values in `ComboboxChips` keep the default chip look; colour a chip only when its category carries meaning, never as decoration.

</Do>

</DoList>

### Don't

<Dont severity="CRITICAL" title="Rendering a Chip outside its group">

<Wrong>

```tsx
<div className="flex flex-wrap gap-1.5">
  <Chip value="sandstone" variant="info">Sandstone</Chip>
</div>
```

</Wrong>

<Correct>

```tsx
<ChipGroup aria-label="Facies" selectionMode="multiple">
  <ChipList>
    <Chip value="sandstone" variant="info">Sandstone</Chip>
  </ChipList>
</ChipGroup>
```

</Correct>

A `Chip` is a row of the group's grid: outside a `ChipList` there is no grid to build it into, so it throws and takes the surrounding tree down with it.

</Dont>

<Dont severity="HIGH" title="Building the remove button by hand">

<Wrong>

```tsx
<ChipGroup aria-label="Horizons">
  <ChipList>
    <Chip value="balder">
      Top Balder
      <Button variant="ghost" size="icon-xs" onClick={() => remove("balder")}><XIcon /></Button>
    </Chip>
  </ChipList>
</ChipGroup>
```

</Wrong>

<Correct>

```tsx
<ChipGroup aria-label="Horizons" onRemove={(values) => remove(values)}>
  <ChipList>
    <Chip value="balder">Top Balder</Chip>
  </ChipList>
</ChipGroup>
```

</Correct>

`onRemove` on the group renders a named remove button in every chip and binds Delete and Backspace; a nested button removes by mouse only and adds a focus stop the grid's arrow keys do not expect.

</Dont>

<Dont severity="HIGH" title="Colouring a chip with className">

<Wrong>

```tsx
<Chip value="fault" className="bg-orange-500 text-white">Fault seal</Chip>
```

</Wrong>

<Correct>

```tsx
<Chip value="fault" variant="warning">Fault seal</Chip>
```

</Correct>

The chip's `className` is merged over `badgeVariants`, so `bg-orange-500` replaces `bg-secondary`, and `orange` is not a Tecton family: the palette emits nothing and the chip loses its surface.

</Dont>

{/* guidelines:end */}

## API Reference

### ChipGroup

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `aria-label` | `string` | - | Names the group. |
| `selectionMode` | `"none" \| "single" \| "multiple"` | `"none"` | Whether chips can be selected. |
| `value` | `string[]` | - | Selected values (controlled). |
| `defaultValue` | `string[]` | - | Initially selected values. |
| `onValueChange` | `(value: string[]) => void` | - | Called with the new selection. |
| `disallowEmptySelection` | `boolean` | `false` | The last selected chip cannot be deselected. |
| `onRemove` | `(values: string[]) => void` | - | Makes the chips removable; called with the values to remove. |
| `disabled` | `boolean` | `false` | Disables every chip. |

### ChipList

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `items` | `Iterable<T>` | - | Data to render a chip for each, with a function as `children`. |
| `children` | `ReactNode \| (item: T) => ReactElement` | - | The chips, or the function that renders one. |
| `empty` | `ReactNode` | - | Shown when the list has no chips. |

### Chip

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `value` | `string` | - | The chip's identity. |
| `label` | `string` | text of `children` | Text for typeahead and screen readers. |
| `variant` | `"default" \| "secondary" \| "destructive" \| "outline" \| "ghost" \| "link" \| "success" \| "warning" \| "info"` | `"secondary"` | Badge colour. |
| `appearance` | `"solid" \| "outline"` | `"solid"` | Filled surface or coloured border. |
| `size` | `"default" \| "md" \| "lg"` | `"default"` | Height 20 / 24 / 28 px. |
| `disabled` | `boolean` | `false` | Disables the chip. |

Style states with `data-selected` and `data-disabled` on a chip and `data-empty` on the list.

### ChipRemove

The remove button a chip renders by itself in a removable group, named "Remove". `children` replaces the X icon.
