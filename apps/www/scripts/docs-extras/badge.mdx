## Status colours

The Tecton style adds `variant="success" | "warning" | "info"` next to `destructive`, and `appearance="outline"` for a transparent badge with a coloured border and text. For a selectable or removable tag use the Tecton [Chip](/docs/tecton/chip), which takes the same `variant`, `appearance` and `size`.

## Sizes

Use `size="default" | "md" | "lg"` (20 / 24 / 28 px); icons scale with the size.
