## Usage

```tsx
import { DatePicker, DateRangePicker } from "@tecton/react/tecton/date-picker"
```

```tsx
const [date, setDate] = React.useState<Date>()

<Field>
  <FieldLabel htmlFor="spud-date">Spud date</FieldLabel>
  <DatePicker id="spud-date" value={date} onValueChange={setDate} />
</Field>
```

`DatePicker` and `DateRangePicker` put a [Calendar](/docs/components/calendar) in a [Popover](/docs/components/popover). The date is written with `Intl.DateTimeFormat`, and the calendar's month and day names come in the same locale: both follow the [TectonProvider](/docs/tecton/provider), as does the direction.

## In a field

The label names the trigger; the date describes it. Give it `className="w-full"` to fill the field.

## Presets

`presets` adds buttons that pick a range at once: `"today"`, `"yesterday"`, `"last7Days"`, `"last30Days"`, `"thisMonth"`, `"lastMonth"` (their labels are translated), or `{ label, value }` of your own. A `value` without `to` is that one day, as `"today"` is.

`minDate` and `maxDate` bound the presets as they bound the calendar: a preset that crosses a bound stops at it, and one wholly outside them is disabled, in its place. Here production is reported up to yesterday (`maxDate`), so "Today" is disabled and "Last 7 days" ends yesterday.

<ComponentPreview name="date-picker-presets" />

## Clear

While there is a date or a range, the calendar ends with a Clear button. It empties the picker, calls `onValueChange(undefined)` and closes the calendar; focus goes back to the trigger. A controlled picker shows what its `value` says: Clear only asks the owner, as a day picked does. In the date input (`variant="input"`), emptying the text clears the date, so its calendar has no Clear.

## Input

`variant="input"` is a date input with a calendar button. It reads the date as the locale writes it ("June 1, 2025", "6/1/2025", "1. Juni 2025") or as an ISO date, and writes it out on blur. Alt+↓ opens the calendar.

## Keyboard

| Key                       | Does                                                   |
| ------------------------- | ------------------------------------------------------ |
| Enter, Space              | Opens the calendar from the button, on the day picked  |
| Alt+↓, ↓                  | Opens the calendar from the date input                 |
| Arrows, Page Up/Down      | Move by day, week or month in the calendar             |
| Enter, Space (on a day)   | Picks the day, closes the calendar, focus goes back    |
| Escape                    | Closes the calendar without a change, focus goes back  |
| Enter, Space (on Clear)   | Empties the date, closes the calendar, focus goes back |
| Enter (in the date input) | Reads the typed date                                   |

## API

### DatePicker

| Prop                                        | Type                                                           | Default                 |
| ------------------------------------------- | -------------------------------------------------------------- | ----------------------- |
| `value` / `defaultValue`                    | `Date \| undefined`                                            | —                       |
| `onValueChange`                             | `(value: Date \| undefined) => void`: `undefined` when cleared | —                       |
| `open` / `defaultOpen`                      | `boolean`                                                      | `false`                 |
| `onOpenChange`                              | `(open: boolean) => void`                                      | —                       |
| `variant`                                   | `"button" \| "input"`                                          | `"button"`              |
| `placeholder`                               | `string`                                                       | "Pick a date"           |
| `minDate` / `maxDate`                       | `Date`                                                         | —                       |
| `format`                                    | `Intl.DateTimeFormatOptions`                                   | `{ dateStyle: "long" }` |
| `captionLayout`                             | `"label" \| "dropdown"`                                        | `"label"`               |
| `disabled`                                  | `boolean`                                                      | `false`                 |
| `name`                                      | `string`: submits `YYYY-MM-DD`                                 | —                       |
| `id`, `className`, `aria-*`, event handlers | on the button, or on the input                                 | —                       |

### DateRangePicker

The same props as `DatePicker` except `variant`, `captionLayout` and `name`, and:

| Prop                     | Type                                                                                                                                     | Default                                               |
| ------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------- |
| `value` / `defaultValue` | `DateRange \| undefined`: `{ from?: Date; to?: Date }`                                                                                   | —                                                     |
| `onValueChange`          | `(value: DateRange \| undefined) => void`: both ends set, or `undefined` when cleared                                                    | —                                                     |
| `numberOfMonths`         | `number`                                                                                                                                 | `2`                                                   |
| `presets`                | `Array<DateRangePresetName \| { label: string; value: DateRange }>`: a `value` without `to` is one day; bounded by `minDate` / `maxDate` | —                                                     |
| `placeholder`            | `string`                                                                                                                                 | "Pick a date range"                                   |
| `format`                 | `Intl.DateTimeFormatOptions`, for both ends                                                                                              | `{ month: "short", day: "numeric", year: "numeric" }` |

For a calendar that stays on the page, use [Calendar](/docs/components/calendar).

## Usage guidelines

### Use it when

- A form field holds one date — a spud date, a report date, a date of birth — picked on a calendar that opens from a button.
- The user may know the date and want to type it: `variant="input"`, a date input with a calendar button.
- A period is picked as a start and an end: `DateRangePicker`, two months side by side, with `presets` such as `"last7Days"` and `"thisMonth"`.

### Not for

- a month grid that stays on the page: use [Calendar](/docs/components/calendar)
- a year or a month picked in a dense form row: use [NativeSelect](/docs/components/native-select)

### Do

<DoList>

<Do>

Put it in a `Field` with an `id` and a `FieldLabel htmlFor`: the label names the trigger and the date describes it.

</Do>

<Do>

Hold plain `Date` values in `value` / `defaultValue` / `onValueChange` (a `{ from, to }` range for `DateRangePicker`); `onValueChange` reports `undefined` when the date is cleared.

</Do>

<Do>

Bound the days with `minDate` / `maxDate`, and pass `captionLayout="dropdown"` when the date is years away (a date of birth).

</Do>

<Do>

Let the `TectonProvider` set the locale: the text, the calendar's month and day names and its first weekday all follow it; change how the date is written with `format` (`Intl.DateTimeFormat` options), never by formatting it yourself.

</Do>

<Do>

Give `className` the width only (`w-full` in a `Field`, `w-48`).

</Do>

</DoList>

### Don't

<Dont severity="HIGH" title="Assembling Popover, Button and Calendar for a date field">

<Wrong>

```tsx
<Popover>
  <PopoverTrigger render={<Button variant="outline" />}>
    {date ? format(date, "PPP") : "Pick a date"}
  </PopoverTrigger>
  <PopoverContent className="w-auto p-0">
    <Calendar mode="single" selected={date} onSelect={setDate} />
  </PopoverContent>
</Popover>
```

</Wrong>

<Correct>

```tsx
<Field>
  <FieldLabel htmlFor="spud-date">Spud date</FieldLabel>
  <DatePicker id="spud-date" value={date} onValueChange={setDate} />
</Field>
```

</Correct>

The hand-built picker writes the date in English whatever the locale, shows the calendar in English, does not close or give focus back when a day is picked, and differs from every other team's copy; `DatePicker` does all of it the same way everywhere.

</Dont>

<Dont severity="HIGH" title="An Input type=&quot;date&quot; next to a calendar button">

<Wrong>

```tsx
<InputGroup>
  <InputGroupInput type="date" value={text} onChange={(e) => setText(e.target.value)} />
  <InputGroupAddon align="inline-end">…</InputGroupAddon>
</InputGroup>
```

</Wrong>

<Correct>

```tsx
<DatePicker id="report-date" variant="input" value={date} onValueChange={setDate} />
```

</Correct>

The `input` variant parses what the user types in the provider's locale ("1. Juni 2025", "6/1/2025", "2025-06-01"), opens the calendar on Alt+↓ and writes the date back out on blur; a native date input looks different in every browser and ignores the provider's locale.

</Dont>

<Dont severity="MEDIUM" title="Two DatePickers for a start and an end">

<Wrong>

```tsx
<DatePicker value={start} onValueChange={setStart} />
<DatePicker value={end} onValueChange={setEnd} />
```

</Wrong>

<Correct>

```tsx
<DateRangePicker value={range} onValueChange={setRange} presets={["last7Days", "last30Days"]} />
```

</Correct>

Two pickers let the end come before the start and show neither the span between them; `DateRangePicker` orders the two days it is given and draws the range across both months.

</Dont>
