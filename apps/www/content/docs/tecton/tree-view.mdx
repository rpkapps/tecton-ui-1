## Usage

```tsx
import {
  TreeView,
  TreeViewItem,
  TreeViewItemContent,
} from "@tecton/react/tecton/tree-view"
```

```tsx
<TreeView aria-label="Project" selectionMode="single" defaultExpanded={["wells"]}>
  <TreeViewItem value="wells">
    <TreeViewItemContent kind="folder">Wells</TreeViewItemContent>
    <TreeViewItem value="a12">
      <TreeViewItemContent>34/10-A-12</TreeViewItemContent>
    </TreeViewItem>
  </TreeViewItem>
</TreeView>
```

The tree is one tab stop with arrow-key navigation and type-ahead; in a right-to-left tree, Left expands and Right collapses.

## Nested

Nest `TreeViewItem`s for a fixed tree. For data, pass `items` and a render function to `TreeView`, and render each node's children with `TreeViewCollection`. Indentation follows the depth.

## States

`selectionMode` with `value` / `defaultValue` / `onValueChange`, and `expanded` / `defaultExpanded` / `onExpandedChange`, all arrays of row `value`s. A `disabled` row cannot be selected, expanded or reached with the arrows; a `hidden` row is dimmed but stays in the tree.

<ComponentPreview name="tree-view-states" />

`disallowEmptySelection` keeps at least one row selected. `empty` is shown in place of the rows when the tree has none.

## Opening rows

`onActivate` is called with a row's `value` when the user opens it: Enter on the focused row, or a click. When rows are also selectable, a click selects and a double click opens, as in a file browser; Ctrl/Cmd- or Shift-click then extends a multiple selection.

```tsx
<TreeView
  aria-label="Project"
  selectionMode="single"
  onActivate={(value) => openWell(value)}
  empty="No wells in this project"
>
  …
</TreeView>
```

## Adornments

`TreeViewItemContent` takes a `colorTag` (a [Color Swatch](/docs/tecton/color-swatch)), a `suffix` (a [Badge](/docs/components/badge)) and an `endAdornment` such as `TreeViewVisibilityToggle` or `TreeViewAction`. Arrow keys move from a row into its controls, and clicking a control neither selects nor expands the row.

<ComponentPreview name="tree-view-adornments" />

`TreeViewVisibilityToggle` is named "Hide" plus the row's label and is pressed while the row is hidden; pass `name` when the label is not plain text. Give `TreeViewAction` an `aria-label`.

## Styling

Rows carry `data-selected`, `data-expanded`, `data-disabled`, `data-hidden` and `data-level` (depth from 1), and are a `group/tree-item`. They are presence attributes; write the selected state as `data-[selected]:…`, since shadcn's `data-selected:` variant matches only `"true"`. Hover and focus are `:hover` and `:focus-visible`, so a control revealed on hover reads:

```tsx
<TreeViewAction
  aria-label="Actions"
  className="opacity-0 group-hover/tree-item:opacity-100 group-focus-within/tree-item:opacity-100 group-data-[selected]/tree-item:opacity-100"
/>
```

## Usage guidelines

### Use it when

- A hierarchy is browsed rather than read: a project tree, a field and well inventory, a layer list.
- Rows carry more than a label: selection, disabled, hidden, a colour, a count, a per-row menu.
- Arrow-key navigation, expansion and type-ahead have to work across the whole structure.

### Not for

- stacked sections that expand, with no parent and child structure: use [Accordion](/docs/components/accordion)
- a flat list of rows with media, a title and actions: use [Item](/docs/components/item)

### Do

<DoList>

<Do>

Give `TreeView` an `aria-label` and every `TreeViewItem` a unique `value`; add `label` when the row content is not plain text.

</Do>

<Do>

Put `TreeViewItemContent` first inside each `TreeViewItem`, then the child `TreeViewItem`s — or `items` on `TreeView` and a `TreeViewCollection` per node for data.

</Do>

<Do>

Drive state with string arrays: `selectionMode`, `value` / `defaultValue` / `onValueChange` and `expanded` / `defaultExpanded` / `onExpandedChange`; mark rows with `disabled` and `hidden` on `TreeViewItem`, and open a row through `onActivate` (Enter, double click on a selectable row), never an `onClick` on its content.

</Do>

<Do>

Hang the extras on `TreeViewItemContent`: `colorTag`, `suffix`, `endAdornment` (`TreeViewVisibilityToggle` with `visible` / `onVisibleChange`, `TreeViewAction` with `onClick`).

</Do>

<Do>

Style rows from the presence attributes `data-selected`, `data-expanded`, `data-disabled`, `data-hidden` and from `:hover` / `:focus-visible` (`group-hover/tree-item:opacity-100`). Write the selected state as `data-[selected]:…`: shadcn's `data-selected:` variant matches only `"true"`.

</Do>

<Do>

The tree opens on the branches the user came for (active field, selected well's parents), not a column of closed folders (`defaultExpanded`).

</Do>

</DoList>

### Don't

<Dont severity="CRITICAL" title="A tree built from nested Collapsibles">

<Wrong>

```tsx
<Collapsible>
  <CollapsibleTrigger>Wells</CollapsibleTrigger>
  <CollapsibleContent className="ps-4">
    <Collapsible>
      <CollapsibleTrigger>34/10-A-12</CollapsibleTrigger>
      <CollapsibleContent className="ps-4">Completions</CollapsibleContent>
    </Collapsible>
  </CollapsibleContent>
</Collapsible>
```

</Wrong>

<Correct>

```tsx
<TreeView aria-label="Project" selectionMode="single" defaultExpanded={["wells"]}>
  <TreeViewItem value="wells">
    <TreeViewItemContent kind="folder">Wells</TreeViewItemContent>
    <TreeViewItem value="a12">
      <TreeViewItemContent>34/10-A-12</TreeViewItemContent>
    </TreeViewItem>
  </TreeViewItem>
</TreeView>
```

</Correct>

Each `Collapsible` is its own widget, so the result is a pile of buttons with no `role="treegrid"`, no arrow-key or type-ahead movement between rows and no selection.

</Dont>

<Dont severity="HIGH" title="Indenting rows with padding classes">

<Wrong>

```tsx
<TreeViewItemContent className="ps-8">34/10-A-12</TreeViewItemContent>
```

</Wrong>

<Correct>

```tsx
<TreeViewItem value="wells">
  <TreeViewItemContent kind="folder">Wells</TreeViewItemContent>
  <TreeViewItem value="a12">
    <TreeViewItemContent>34/10-A-12</TreeViewItemContent>
  </TreeViewItem>
</TreeViewItem>
```

</Correct>

`TreeViewItemContent` writes `paddingInlineStart` as an inline style from the row's depth, which no `className` can outrank, so the nesting sets the indent and `ps-8` is dead weight.

</Dont>

<Dont severity="MEDIUM" title="Styling rows on hover or focus attributes">

<Wrong>

```tsx
<TreeViewAction className="opacity-0 group-data-hovered/tree-item:opacity-100" aria-label="Actions" />
```

</Wrong>

<Correct>

```tsx
<TreeViewAction className="opacity-0 group-hover/tree-item:opacity-100 group-focus-within/tree-item:opacity-100" aria-label="Actions" />
```

</Correct>

Rows expose no hover, press or focus attributes: use `:hover`, `:active`, `:focus-visible` and `:focus-within`, and the presence attributes for state.

</Dont>

## API Reference

### TreeView

Forwards `id`, `className`, `style`, `aria-labelledby`, `aria-describedby` and `data-*` attributes; the tree handles pointer and keyboard events itself.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `aria-label` | `string` | - | Accessible name of the tree. |
| `selectionMode` | `"none" \| "single" \| "multiple"` | `"none"` | Row selection. |
| `value` | `string[]` | - | Selected rows (controlled). |
| `defaultValue` | `string[]` | - | Initially selected rows. |
| `onValueChange` | `(value: string[]) => void` | - | Called with the selected rows. |
| `disallowEmptySelection` | `boolean` | `false` | Keeps at least one row selected. |
| `onActivate` | `(value: string) => void` | - | Called when a row is opened (Enter, click; double click when rows are selectable). |
| `empty` | `ReactNode` | - | Shown in place of the rows when there are none. |
| `expanded` | `string[]` | - | Expanded rows (controlled). |
| `defaultExpanded` | `string[]` | - | Initially expanded rows. |
| `onExpandedChange` | `(expanded: string[]) => void` | - | Called with the expanded rows. |
| `items` | `Iterable<T>` | - | Data for the top-level rows; `children` is then `(item: T) => ReactNode`. |

### TreeViewItem

One row: a `TreeViewItemContent` first, then child `TreeViewItem`s or a `TreeViewCollection`. Forwards `className`, `style` and `data-*` attributes.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `value` | `string` | - | The row's identity, unique in the tree. |
| `label` | `string` | content text | Plain-text name for type-ahead and announcements; needed when the content is not plain text. |
| `disabled` | `boolean` | `false` | Not selectable, not expandable, skipped by the arrow keys. |
| `hidden` | `boolean` | `false` | Dimmed hidden state; the row stays in the tree. |

### TreeViewCollection

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `items` | `Iterable<T>` | - | Data for the child rows. |
| `children` | `(item: T) => ReactNode` | - | Renders one `TreeViewItem` per entry. |

### TreeViewItemContent

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `kind` | `"folder" \| "item"` | `"item"` | Folder icon or a small dot. |
| `icon` | `ReactNode` | - | Custom leading icon. |
| `colorTag` | `ReactNode` | - | 12 px colour tag after the icon. |
| `suffix` | `ReactNode` | - | Content after the label. |
| `endAdornment` | `ReactNode` | - | Trailing controls. |

### TreeViewAction

A 24 px icon button; a vertical ellipsis unless you pass children. Forwards `id`, `className`, `style`, `aria-labelledby`, `aria-describedby`, `aria-pressed`, `aria-expanded`, `aria-haspopup`, `aria-controls` and `data-*` attributes.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `aria-label` | `string` | - | Accessible name, e.g. "Actions for Faults". |
| `onClick` | `() => void` | - | Called on activation. |
| `disabled` | `boolean` | `false` | Disables the button. |

### TreeViewVisibilityToggle

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `visible` | `boolean` | `true` | Current visibility; pressed while `false`. |
| `onVisibleChange` | `(visible: boolean) => void` | - | Called with the next value. |
| `name` | `string` | row label | What the toggle hides, for the name `Hide {name}`. |
| `disabled` | `boolean` | `false` | Disables the toggle. |
