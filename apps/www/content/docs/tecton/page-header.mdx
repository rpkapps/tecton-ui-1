## Usage

```tsx
import {
  PageHeader,
  PageHeaderActions,
  PageHeaderContent,
  PageHeaderDescription,
  PageHeaderEyebrow,
  PageHeaderNav,
  PageHeaderTitle,
} from "@tecton/react/tecton/page-header"
```

```tsx
<PageHeader>
  <PageHeaderContent>
    <PageHeaderEyebrow>Gullfaks / Wells</PageHeaderEyebrow>
    <PageHeaderTitle>34/10-A-12</PageHeaderTitle>
    <PageHeaderDescription>Drilled 2019 · TD 3 250 m</PageHeaderDescription>
  </PageHeaderContent>
  <PageHeaderActions>
    <Button>New well</Button>
  </PageHeaderActions>
</PageHeader>
```

## Actions

`PageHeaderActions` is an [Overflow](/docs/tecton/overflow) row. Wrap secondary actions in `OverflowItem` so a narrow header drops their labels, then moves them into a More menu; leave the primary action bare. The title takes up to 60 % of the width. The actions collapse before anything wraps; only when the primary action and the More button no longer fit beside the title does the action row move below it.

<ComponentPreview name="page-header-actions" align="start" />

## Section tabs

`PageHeaderNav` holds section tabs and keeps its natural width. To let the tabs collapse too, put the nav inside `PageHeaderActions` as an `OverflowItem` with a `priority` and a menu form, then an `OverflowSpacer`, then the actions. Here the view toggle (priority 1) leaves first and the tabs (priority 2) follow, all at once, as a radio group in the menu.

## Usage guidelines

### Use it when

- The block at the top of a page: what the user is looking at, and what they can do to it.
- The title needs an eyebrow (a breadcrumb or category), a description, or section tabs.
- The actions have to survive a narrow window without the header stacking.

### Not for

- the title row of a panel or an inspector: use [PanelHeader](/docs/tecton/panel)
- the top bar of the application frame: use [AppShellHeader](/docs/tecton/app-shell)
- a heading inside a card: use [CardTitle](/docs/components/card)

### Do

<DoList>

<Do>

Put the eyebrow, title and description inside `PageHeaderContent`; put the actions in `PageHeaderActions`.

</Do>

<Do>

Leave the primary action unwrapped in `PageHeaderActions`, and wrap secondary ones in `OverflowItem` with a `priority` so they collapse first.

</Do>

<Do>

Use `PageHeaderNav` for section tabs and give it an `aria-label`; it is a bare `nav`.

</Do>

<Do>

Let `PageHeaderTitle` be the `h1`: one per page, no heading level or size set through `className`.

</Do>

</DoList>

### Don't

<Dont severity="HIGH" title="Title and actions as direct children of PageHeader">

<Wrong>

```tsx
<PageHeader>
  <PageHeaderTitle>Gullfaks field development</PageHeaderTitle>
  <PageHeaderDescription>Three alternatives.</PageHeaderDescription>
  <PageHeaderActions>
    <Button>New alternative</Button>
  </PageHeaderActions>
</PageHeader>
```

</Wrong>

<Correct>

```tsx
<PageHeader>
  <PageHeaderContent>
    <PageHeaderTitle>Gullfaks field development</PageHeaderTitle>
    <PageHeaderDescription>Three alternatives.</PageHeaderDescription>
  </PageHeaderContent>
  <PageHeaderActions>
    <Button>New alternative</Button>
  </PageHeaderActions>
</PageHeader>
```

</Correct>

`PageHeader` is a `flex flex-wrap` row, so without `PageHeaderContent` the title and the description become siblings of the action row: the title loses its truncation and its 60% cap, and the description wraps onto its own line.

</Dont>

<Dont severity="MEDIUM" title="A hand-built header row instead of PageHeader">

<Wrong>

```tsx
<div className="flex items-center justify-between">
  <h1 className="text-2xl font-bold text-zinc-900">34/10-A-12</h1>
  <Button>Edit</Button>
</div>
```

</Wrong>

<Correct>

```tsx
<PageHeader>
  <PageHeaderContent>
    <PageHeaderTitle>34/10-A-12</PageHeaderTitle>
  </PageHeaderContent>
  <PageHeaderActions>
    <Button>Edit</Button>
  </PageHeaderActions>
</PageHeader>
```

</Correct>

`text-zinc-900` is stock Tailwind and emits no CSS under Tecton's reset palette, and a hand-built row has neither the title truncation nor the collapsing action row, so it overflows as soon as the window narrows.

</Dont>

{/* guidelines:end */}

## API Reference

### PageHeader, PageHeaderContent, PageHeaderEyebrow, PageHeaderTitle, PageHeaderDescription, PageHeaderNav

Styled elements that accept the props of the element they render: `PageHeader` is a `header`, `PageHeaderTitle` an `h1`, `PageHeaderDescription` a `p`, and `PageHeaderNav` a `nav` (give it an `aria-label`).

### PageHeaderActions

An [Overflow](/docs/tecton/overflow#toolbar-overflow) row; accepts every `Overflow` prop. It is not a toolbar, so a tab list inside keeps its own arrow keys.
