## Usage

```tsx
import {
  SelectField,
  SelectFieldItem,
  SelectFieldLabel,
  SelectFieldDescription,
  SelectFieldError,
} from "@tecton/react/tecton/select-field"
```

```tsx
<SelectField label="Facies" placeholder="Select a facies">
  <SelectFieldItem id="sandstone">Sandstone</SelectFieldItem>
  <SelectFieldItem id="shale">Shale</SelectFieldItem>
</SelectField>
```

<Callout title="Composes the shadcn Select">
  `SelectField` renders `Select`, `SelectTrigger`, `SelectValue` and `SelectContent` from [Select](/docs/components/select) and only adds the label, helper text and Tecton variants. The `items` prop with a render-function child is typed as the `Select` render props rather than as an item, so the examples map over data instead.
</Callout>

## Variants

Use the `variant` prop; the trigger gets the same treatment as the [Text Field](/docs/tecton/text-field) variants.

## Dynamic items

Map over your data to render `SelectFieldItem`s. Give each item an `id` and a `textValue`; control the value with `selectedKey` / `onSelectionChange`.

## API Reference

### SelectField

The shadcn `Select` (single selection) with a label, trigger, helper text and popover already composed. Accepts all `Select` props (`selectedKey`, `defaultSelectedKey`, `onSelectionChange`, `isDisabled`, `isRequired`, `name`…).

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `variant` | `"outlined" \| "filled" \| "textOnly"` | "outlined" | Visual variant of the trigger. |
| `size` | `"default" \| "sm"` | "default" | Trigger height. |
| `label` | `ReactNode` | - | Renders a `SelectFieldLabel`. |
| `description` | `ReactNode` | - | Renders a `SelectFieldDescription`. |
| `errorMessage` | `ReactNode` | - | Renders a `SelectFieldError` and sets `isInvalid`. |
| `placeholder` | `string` | - | Placeholder shown in the trigger. |
| `items` | `Iterable<T>` | - | Dynamic items; children must then be a render function (see note below). |
| `contentProps` | `SelectContentProps` | - | Props forwarded to the popover content. |

### SelectFieldItem

Alias of the shadcn `SelectItem` (React Aria `ListBoxItem`).

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `id` | `Key` | - | Value of the option. |
| `textValue` | `string` | - | Plain-text label; inferred from string children. |
