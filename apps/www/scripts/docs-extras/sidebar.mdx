## Several sidebars in one document

A page that mounts independently deployed applications ([Micro-frontends](/docs/micro-frontends)) can end up with more than one `SidebarProvider`. By default every provider writes the same `sidebar_state` cookie, so the last one to toggle decides what every sidebar restores.

`cookieName` on `SidebarProvider` makes a provider self-contained:

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `cookieName` | `string \| false` | `"sidebar_state"` | Cookie the open state is persisted in. `false` writes no cookie at all. |

```tsx lineNumbers
<SidebarProvider cookieName="mfe_a_sidebar">
  <Sidebar />
</SidebarProvider>
```

Give the shell the default and each mounted application a name of its own, or `false`.
