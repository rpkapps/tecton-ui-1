## Usage

```tsx
import {
  createColumns,
  DataTable,
  DataTableActionBar,
  DataTableContent,
  DataTableFilter,
  DataTableFooter,
  DataTablePagination,
  DataTableSearch,
  DataTableToolbar,
} from "@tecton/react/tecton/data-table"
```

```tsx
const columns = createColumns<Well>([
  { id: "name", header: "Well" },
  { id: "status", header: "Status", type: "options", options: STATUSES },
  { id: "depth", header: "TD (m)", type: "number" },
  { id: "spud", header: "Spud date", type: "date" },
])

<DataTable items={wells} columns={columns} selectionMode="multiple" filterable pagination>
  <DataTableToolbar>
    <DataTableSearch />
    <DataTableFilter column="status" />
  </DataTableToolbar>
  <DataTableActionBar>
    <Button size="sm" onClick={shutIn}>Shut in</Button>
  </DataTableActionBar>
  <DataTableContent aria-label="Wells" />
  <DataTableFooter>
    <DataTablePagination pageSizes={[10, 25, 50]} />
  </DataTableFooter>
</DataTable>
```

Each item needs an `id` (or pass `itemToId`). Make the columns once, at module level or in a `React.useMemo`. Use [Table](/docs/components/table) for a short table that is read, not worked with.

## Composition

```text
DataTable
├── DataTableToolbar
│   ├── DataTableSearch
│   ├── DataTableFilter
│   ├── DataTableGroupBy
│   └── DataTableColumnsMenu
├── DataTableActionBar
├── DataTableActiveFilters
├── DataTableContent
│   └── DataTableRowActions (in a column's cell)
└── DataTableFooter
    └── DataTablePagination
```

The root holds the state and turns features on (`selectionMode`, `pagination`, `filterable`, `groupable`, `…Columns`); a part for a feature that is off renders nothing and warns in development.

## Columns

A column's `type` sets how its values are shown, aligned and sorted; `cell` draws your own content, and a column with `columns` is a group.

<ComponentPreview name="data-table-columns" align="start" />

| `type` | Align | Shown as | Sorted |
| --- | --- | --- | --- |
| `"text"` (default) | start | the text | natural, case-insensitive |
| `"number"` | end | `Intl.NumberFormat` with `format` | numerically |
| `"date"` | start | `Intl.DateTimeFormat` with `format` | chronologically |
| `"boolean"` | center | a check for `true` | `false` first |
| `"options"` | start | a [Badge](/docs/components/badge) per option | in `options` order |

Empty values sort last. Return raw numbers and `Date`s from `accessor`, not formatted text.

## Resizing

`resizableColumns` adds a resizer to each header and Resize, Fit to content and Reset width to the column menus.

<ComponentPreview name="data-table-column-resizing" align="start" />

For a plain [Table](/docs/components/table), put a `TableColumnResizer` last in each `TableHead` and keep the widths yourself.

```tsx
<TableHead className="relative" style={{ width: widths.field }}>
  Field
  <TableColumnResizer
    label="Field"
    value={widths.field}
    min={80}
    onValueChange={(width) => setWidths((w) => ({ ...w, field: width }))}
  />
</TableHead>
```

## Hiding, pinning and reordering

`DataTableColumnsMenu` lists the columns to show, hide or pin; each header's menu has the same actions.

<ComponentPreview name="data-table-column-pinning" align="start" />

| Root prop | The user | View field | Column opt-out |
| --- | --- | --- | --- |
| `resizableColumns` | drags or fits a column's width | `columns.widths` | `resizable: false` |
| `reorderableColumns` | drags a header to a new place | `columns.order` | `reorderable: false` |
| `hideableColumns` | hides a column | `columns.hidden` | `hideable: false` |
| `pinnableColumns` | pins a column to the start or end | `columns.pinned` | `pinnable: false` |

Pinned cells are opaque in `var(--surface)`; a custom surface sets it: `className="bg-muted [--surface:var(--color-muted)]"`.

## Search and filters

`filterable` turns on `DataTableSearch`, a `DataTableFilter` per column and `DataTableActiveFilters`. The toolbar collapses its items into an overflow menu when it runs out of room.

<ComponentPreview name="data-table-filters" align="start" />

| `type` | Filter | Value in the view |
| --- | --- | --- |
| `text` | contains the text | `{ type: "text", value }` |
| `number` | minimum and maximum | `{ type: "number", min?, max? }` |
| `date` | a [date range picker](/docs/components/date-picker) | `{ type: "date", from?, to? }` |
| `boolean` | Any, Yes or No | `{ type: "boolean", value }` |
| `options` | a checkbox per option, with counts | `{ type: "options", values }` |

Search matches the shown columns' display text, ignoring case and accents. A column's own `filter(item, value)` replaces its type's.

## Selection

`selectionMode="single"` or `"multiple"` adds a checkbox column. `DataTableActionBar` shows while rows are selected, with the count, Clear and your actions.

<ComponentPreview name="data-table-selection" align="start" />

| Prop | Does |
| --- | --- |
| `value` / `onValueChange` | The selected row ids. |
| `isItemDisabled` | Disables rows; `disabledBehavior="selection"` keeps them focusable and openable. |
| `onActivate(id, item)` | Called when a row opens: <Kbd>Enter</Kbd>, a double click, or a click while no row is selected. |
| `itemToHref` | Makes each row header a link, followed through the [TectonProvider](/docs/tecton/provider)'s router. |

Select all selects every row the view matches, on every page.

## Virtualized rows

`virtualized` on `DataTableContent` renders only the rows in view; give the root or the content a bounded height.

<ComponentPreview name="data-table-virtual" align="start" />

For rows sent in batches, `hasMore` and `onLoadMore` load more as the user scrolls; set `loading` while a batch is out and `error` when it fails.

```tsx
<DataTable items={rows} columns={columns} hasMore={rows.length < total} onLoadMore={loadNext} loading={isLoading} className="h-96">
  <DataTableContent aria-label="Gauge readings" virtualized />
</DataTable>
```

## Trees and detail rows

`itemToChildren` makes the rows a tree; `renderDetail` on `DataTableContent` gives each row an expandable detail row instead.

<ComponentPreview name="data-table-tree" align="start" />

```tsx
<DataTableContent aria-label="Wells" renderDetail={(well: Well) => <Perforations well={well} />} />
```

Both use `expanded` / `onExpandedChange`. In server mode, a row whose children are `undefined` loads them on open.

## Grouping and totals

`groupable` with `DataTableGroupBy` groups rows by columns, with subtotals; `totals` on `DataTableContent` adds a footer row.

<ComponentPreview name="data-table-grouping" align="start" />

Number columns sum and boolean columns count by default; set `aggregate` (`"avg"`, `"min"`, `"max"`, `"count"`, `"countDistinct"` or a function) and `renderAggregate` per column.

## States

`loading`, `error` with `onRetry`, and `empty` and `noResults` on `DataTableContent` replace the rows.

<ComponentPreview name="data-table-states" align="start" />

| State | When | Customize |
| --- | --- | --- |
| Loading | `loading`: skeleton rows, or a bar over existing rows | - |
| Error | `error` set | `error` content, `onRetry` |
| Empty | no rows | `empty` |
| No results | nothing matches the search and filters | `noResults` |

## Server data

With `dataMode="server"`, the table reports each view and page change and shows the `items` the server returns; `rowCount` is the server's total.

<ComponentPreview name="data-table-server" align="start" />

| | Client | Server |
| --- | --- | --- |
| Sort, search, filter, page | the table | the server, from `onViewChange` / `onPageChange` |
| Option counts | from `items` | each option's `count` |
| Totals, export | every matching row | the loaded rows |
| "Select all N" | every matching row | all matching: `eventDetails.allMatching.except` |

## The view

The sorting, search, filters, grouping and column layout are one JSON object: start from `defaultView`, or control it with `view` / `onViewChange`.

```tsx
<DataTable
  items={wells}
  columns={columns}
  defaultView={JSON.parse(savedView)}
  onViewChange={(view) => saveView(JSON.stringify(view))}
>
```

A saved view is reconciled with the columns: unknown or opted-out columns are dropped, never thrown on.

## Keyboard

The table is one tab stop; focus is on a row, or on a cell once the arrows move into the row.

| Key | Does |
| --- | --- |
| <Kbd>↓</Kbd> / <Kbd>↑</Kbd> | Next / previous row, or cell below / above |
| <Kbd>→</Kbd> / <Kbd>←</Kbd> | Into and between cells and their controls; opens / closes a tree row, group or detail row |
| <Kbd>Home</Kbd> / <Kbd>End</Kbd> | First / last row, or cell of the row |
| <Kbd>Ctrl</Kbd> / <Kbd>⌘</Kbd> + <Kbd>Home</Kbd> / <Kbd>End</Kbd> | First / last cell of the table |
| <Kbd>Page Up</Kbd> / <Kbd>Page Down</Kbd> | A screenful of rows |
| Letters | Next row whose row header starts with the text |
| <Kbd>Space</Kbd> | Selects or clears the row, or a group's rows |
| <Kbd>Shift</Kbd> + <Kbd>Space</Kbd> / <Kbd>↓</Kbd> / <Kbd>↑</Kbd> | Extends the selection |
| <Kbd>Ctrl</Kbd> / <Kbd>⌘</Kbd> + <Kbd>A</Kbd> | Selects every row |
| <Kbd>Escape</Kbd> | Clears the selection |
| <Kbd>Enter</Kbd> | Opens the row (`onActivate`, its link) |
| <Kbd>Enter</Kbd> / <Kbd>F2</Kbd> | Into a cell's field; <Kbd>Escape</Kbd> back to the cell |
| <Kbd>Enter</Kbd> / <Kbd>Space</Kbd> on a header | Starts moving the column (`reorderableColumns`) |
| <Kbd>←</Kbd> / <Kbd>→</Kbd> on a resizer | Narrows / widens the column; <Kbd>Enter</Kbd> keeps, <Kbd>Escape</Kbd> reverts |

## Accessibility

- A grid, or a treegrid with trees, details or groups.
- Name it with `aria-label` on `DataTableContent`.
- Rows named by their row header column.
- Sort, selection and result counts announced.
- Full `aria-rowcount` on pages and virtualized rows.
- Focus never drops to the page.

## RTL

Direction and locale come from the [TectonProvider](/docs/tecton/provider): columns, arrow keys and pinning mirror, and numbers, dates and the table's own texts are localized. Column headers are your own texts.

## API Reference

### DataTable

The root `div`. Every `on…Change` gets the new value and `eventDetails` (`reason`, `event`, `cancel()`).

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `items` | `ReadonlyArray<T>` | - | The rows; in server mode, the view's page. |
| `columns` | `DataTableColumns<T>` | - | From `createColumns`. |
| `itemToId` | `(item: T) => string` | `String(item.id)` | A row's id. |
| `itemToChildren` | `(item: T) => ReadonlyArray<T> \| undefined` | - | Makes the rows a tree. |
| `itemToHref` | `(item: T) => string \| undefined` | - | Makes each row a link. |
| `isItemDisabled` | `(item: T) => boolean` | - | Disables rows. |
| `disabledBehavior` | `"all" \| "selection"` | `"all"` | What a disabled row cannot do. |
| `dataMode` | `"client" \| "server"` | `"client"` | Who sorts, filters and pages. |
| `rowCount` | `number` | - | Server mode: rows the view matches. |
| `loading` | `boolean` | `false` | Shows the loading state. |
| `error` | `ReactNode` | - | Shows the error state; `true` for the default text. |
| `onRetry` | `() => void` | - | Adds Retry to the error state. |
| `hasMore` | `boolean` | `false` | More rows follow; not with `pagination`. |
| `onLoadMore` | `() => void` | - | Called when the end of the rows nears. |
| `size` | `"default" \| "sm"` | `"default"` | Compact rows. |
| `striped` | `boolean` | `false` | Alternate row fills. |
| `sortable` | `boolean` | `true` | Headers sort; <Kbd>Shift</Kbd> + click by several. |
| `filterable` | `boolean` | `false` | Turns on search and filters. |
| `groupable` | `boolean` | `false` | Turns on grouping. |
| `resizableColumns` | `boolean` | `false` | Users resize columns. |
| `reorderableColumns` | `boolean` | `false` | Users reorder columns. |
| `hideableColumns` | `boolean` | `false` | Users hide columns. |
| `pinnableColumns` | `boolean` | `false` | Users pin columns. |
| `pagination` | `boolean` | `false` | Shows a page at a time. |
| `selectionMode` | `"none" \| "single" \| "multiple"` | `"none"` | Row selection. |
| `value` | `ReadonlyArray<string>` | - | Selected ids (controlled). |
| `defaultValue` | `ReadonlyArray<string>` | `[]` | Initially selected ids. |
| `onValueChange` | `(value, eventDetails) => void` | - | Called with the selected ids; `eventDetails.allMatching` in server mode. |
| `disallowEmptySelection` | `boolean` | `false` | Keeps one row selected. |
| `view` | `DataTablePartialView` | - | The view (controlled). |

| `expanded` | `ReadonlyArray<string>` | - | Open tree and detail rows (controlled). |
| `defaultExpanded` | `ReadonlyArray<string>` | `[]` | Initially open rows. |

| `page` | `number` | - | The page, from 1 (controlled). |
| `defaultPage` | `number` | `1` | The initial page. |
| `onPageChange` | `(page, eventDetails) => void` | - | Called with the new page; `reason` is `"previous"`, `"next"` or `"page"` from `DataTablePagination`, else `"reset"`, `"page-size"`, `"clamp"` or `"group"`. |

| `defaultPageSize` | `number` | `10` | Initial rows per page. |
| `onPageSizeChange` | `(pageSize, eventDetails) => void` | - | Called with the new page size. |
| `pageSizes` | `ReadonlyArray<number>` | `[10, 20, 50, 100]` | The page sizes `DataTablePagination` offers. |

### createColumns

`createColumns<T>(columns)` validates the columns for `DataTable`; it throws on an empty or repeated id.

| Field | Type | Default | Description |
| --- | --- | --- | --- |
| `id` | `string` | - | Unique id, used by the view. |
| `header` | `string` | - | Header text and accessible name. |
| `type` | `"text" \| "number" \| "date" \| "boolean" \| "options"` | `"text"` | Display, alignment and sort. |
| `accessor` | `keyof T \| (item: T) => DataTableValue` | `item[id]` | The cell's raw value. |
| `format` | `Intl.NumberFormatOptions \| Intl.DateTimeFormatOptions` | - | Number or date format. |
| `options` | `ReadonlyArray<DataTableOption>` | - | `{ value, label, variant?, count? }`, in sort order. |
| `cell` | `(item: T, details) => ReactNode` | - | Custom cell content. |
| `renderHeader` | `(details) => ReactNode` | - | Custom header content. |
| `align` | `"start" \| "center" \| "end"` | by type | Cell and header alignment. |
| `compare` | `(a: T, b: T) => number` | - | Custom ascending sort. |
| `filter` | `(item: T, value: DataTableFilterValue) => boolean` | - | Custom filter. |
| `aggregate` | `"sum" \| "avg" \| "min" \| "max" \| "count" \| "countDistinct" \| function` | by type | Group and totals figure. |
| `renderAggregate` | `(value, { items }) => ReactNode` | - | Custom aggregate content. |
| `rowHeader` | `boolean` | first column | Names each row. |
| `description` | `string` | - | Info popover in the header. |
| `width` | `number` | content | Initial width in px. |
| `minWidth`, `maxWidth` | `number` | `48`, - | Width bounds in px. |
| `hideBelow` | `"sm" \| "md" \| "lg"` | - | Hidden below the breakpoint. |
| `wrap` | `boolean` | `false` | Multi-line text; not virtualized. |
| `sortable`, `filterable`, `groupable` | `false` | - | Opts out of the feature. |
| `resizable`, `reorderable`, `hideable`, `pinnable` | `false` | - | Opts out of the feature. |

A group is `{ id, header, description?, columns }`. `cell` gets `{ id, column, value, text, depth }`; `renderHeader` gets `{ column, header, sorted }`.

### DataTableView

```ts
type DataTableView = {
  sorting: ReadonlyArray<{ column: string; direction: "ascending" | "descending" }>
  search: string
  filters: Readonly<Record<string, DataTableFilterValue>>
  grouping: ReadonlyArray<string>
  columns: {
    order: ReadonlyArray<string>
    hidden: ReadonlyArray<string>
    widths: Readonly<Record<string, number>>
    pinned: { start: ReadonlyArray<string>; end: ReadonlyArray<string> }
  }
}

// `view` and `defaultView` take a DataTablePartialView: every part optional.
type DataTableFilterValue =
  | { type: "text"; value: string }
  | { type: "number"; min?: number; max?: number }
  | { type: "date"; from?: Date; to?: Date }
  | { type: "boolean"; value: boolean }
  | { type: "options"; values: ReadonlyArray<string> }
  | { type: "custom"; value: unknown }
```
