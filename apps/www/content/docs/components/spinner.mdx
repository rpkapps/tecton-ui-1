## Usage

```tsx
import { Spinner } from "@tecton/react/components/spinner"
```

```tsx
<Spinner />
```

## Customization

You can replace the default spinner icon with any other icon by editing the `Spinner` component.

<ComponentPreview name="spinner-custom" />

```tsx lineNumbers title="@tecton/react/components/spinner.tsx"
import { cn } from "cn"
import { LoaderIcon } from "lucide-react"

function Spinner({ className, ...props }: React.ComponentProps<"svg">) {
  return (
    <LoaderIcon
      role="status"
      aria-label="Loading"
      className={cn("size-4 animate-spin", className)}
      {...props}
    />
  )
}

export { Spinner }
```

## Usage guidelines

### Use it when

- A control is busy: a `Button` that is saving, an `InputGroup` that is validating, a `Badge` that says "Generating".
- A small region is waiting, and the wait is short and cannot be measured.
- An `Empty` state stands in for a running operation, with the spinner inside `EmptyMedia`.

### Not for

- a measurable percentage: use [Progress](/docs/components/progress)
- a ring with the value in the middle: use [CircularProgress](/docs/tecton/circular-progress)
- a placeholder that holds the page layout while content loads: use [Skeleton](/docs/components/skeleton)

### Do

<DoList>

<Do>

Inside a `Button`, a `Badge` or an `InputGroupAddon`, give it `data-icon="inline-start"` or `data-icon="inline-end"` so the control trims its padding on that side.

</Do>

<Do>

Mark the control that is working with `isPending`, not `isDisabled`, so it keeps focus and cannot be pressed twice; make the label a verb: "Saving…".

</Do>

<Do>

Resize with `size-*` only (`size-3`, `size-6`); the stroke is `currentColor`, so set the colour on the parent with a semantic token.

</Do>

<Do>

`Spinner` already carries `role="status"` and `aria-label="Loading"`; do not wrap it in a second live region.

</Do>

<Do>

A standalone `Spinner` says what is loading ("Loading well logs"); inside a labelled button it keeps the default label.

</Do>

<Do>

A view that loads as one unit shows one loading state; panels that load independently each show their own `Skeleton`, not a spinner per card.

</Do>

</DoList>

### Don't

<Dont severity="HIGH" title="A spinner in a button without data-icon">

<Wrong>

```tsx
<Button isPending size="sm">
  <Spinner />
  Saving…
</Button>
```

</Wrong>

<Correct>

```tsx
<Button isPending size="sm">
  <Spinner data-icon="inline-start" />
  Saving…
</Button>
```

</Correct>

The button trims its leading padding only through `has-data-[icon=inline-start]:pl-1.5`, so without the attribute the spinner sits in full text padding and the button jumps in width the moment it appears.

</Dont>

<Dont severity="HIGH" title="A hand-rolled spinner div with borders">

<Wrong>

```tsx
<div className="size-4 animate-spin rounded-full border-2 border-gray-300 border-t-blue-600" />
```

</Wrong>

<Correct>

```tsx
<Spinner />
```

</Correct>

`gray-300` and `blue-600` are not Tecton steps, so the reset palette gives the ring no colour at all, and the bare `div` has neither `role="status"` nor an accessible name.

</Dont>

<Dont severity="MEDIUM" title="Colouring the spinner with a stock class">

<Wrong>

```tsx
<Spinner className="size-5 text-gray-500" />
```

</Wrong>

<Correct>

```tsx
<Spinner className="size-5 text-muted-foreground" />
```

</Correct>

`gray-500` is not a Tecton step, so the class emits no CSS and the spinner keeps whatever colour it inherits — it looks right only where the parent already happens to be muted.

</Dont>

{/* guidelines:end */}
