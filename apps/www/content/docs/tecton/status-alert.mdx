## Usage

```tsx
import { StatusAlert } from "@tecton/react/tecton/status-alert"
```

```tsx
<StatusAlert
  severity="warning"
  title="Unsaved changes"
  description="Three horizons have edits that are not yet committed."
  action={<Button variant="ghost" size="sm">Save</Button>}
  onDismiss={() => setOpen(false)}
/>
```

<Callout title="Composes the shadcn Alert">
  `StatusAlert` renders the shadcn `Alert`, `AlertTitle`, `AlertDescription` and `AlertAction` primitives and only adds the Tecton severity colours (`--destructive`, `--warning`, `--info`, `--success`) and the toolbar. The plain [Alert](/docs/components/alert) is still available for neutral callouts.
</Callout>

## Severities

Use the `severity` prop. Each severity has a default icon; pass `icon` to override it or `icon={false}` to remove it.

Use `variant="outlined"` for a transparent alert with a coloured border and text.

Pass an `action` element; it is rendered in a trailing toolbar and styled to match the alert colour. Ghost `Button`s work best.

## API Reference

### StatusAlert

Accepts all `Alert` props except `variant`.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `severity` | `"error" \| "warning" \| "info" \| "success"` | "info" | Colour and default icon. |
| `variant` | `"filled" \| "outlined"` | "filled" | Solid surface or coloured border. |
| `title` | `ReactNode` | - | Rendered in `AlertTitle`. |
| `description` | `ReactNode` | - | Rendered in `AlertDescription`. |
| `icon` | `ReactNode \| false` | severity icon | Custom leading icon; `false` hides it. |
| `action` | `ReactNode` | - | Trailing action (e.g. a ghost `Button`). |
| `onDismiss` | `() => void` | - | Renders a dismiss button when set. |
| `dismissLabel` | `string` | "Dismiss" | Accessible label of the dismiss button. |
| `children` | `ReactNode` | - | Extra content after the description. |
