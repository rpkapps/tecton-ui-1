## Usage

```tsx
import { Chip, ChipRemove, ChipGroup, ChipList, ChipTag } from "@tecton/react/tecton/chip"
```

```tsx
<Chip color="primary" variant="outlined" size="sm">
  Top Balder
</Chip>
```

<Callout title="Chip, not Badge">
  In the Tecton design system a small label is a *Chip*; the shadcn `Badge` component is intentionally left untouched. What Tecton calls a *Badge* (a count anchored to an icon) is the [CountBadge](/docs/tecton/count-badge) component.
</Callout>

## Group

`ChipGroup`, `ChipList` and `ChipTag` wrap React Aria's `TagGroup` for a keyboard-navigable, selectable and removable collection. `ChipTag` renders the remove button automatically when the group has an `onRemove` handler.

## API Reference

### Chip

A static chip (`span`) or, when `onPress` is set, a React Aria `Button`.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `color` | `"default" \| "primary" \| "error" \| "warning" \| "info" \| "success"` | "default" | Semantic colour. |
| `variant` | `"filled" \| "outlined"` | "filled" | Filled surface or coloured border. |
| `size` | `"md" \| "sm" \| "xs"` | "md" | Height 28 / 24 / 20 px. |
| `onPress` | `(e: PressEvent) => void` | - | Makes the chip interactive. |
| `isDisabled` | `boolean` | false | Disables the chip. |

### ChipRemove

A small React Aria `Button` with an `X` icon, placed at the end of a `Chip`.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `onPress` | `(e: PressEvent) => void` | - | Remove handler. |
| `children` | `ReactNode` | `<XIcon />` | Custom icon. |

### ChipGroup

React Aria [`TagGroup`](https://react-aria.adobe.com/TagGroup) with Tecton spacing. Accepts all `TagGroup` props.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `selectionMode` | `"none" \| "single" \| "multiple"` | "none" | Enables selection of `ChipTag`s. |
| `onRemove` | `(keys: Set<Key>) => void` | - | When set, tags render a remove button. |
| `aria-label` | `string` | - | Accessible name of the group. |

### ChipList

React Aria `TagList`; pass `items` and a render function or static `ChipTag` children.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `items` | `Iterable<T>` | - | Dynamic collection items. |
| `renderEmptyState` | `() => ReactNode` | - | Content when the list is empty. |

### ChipTag

React Aria `Tag` styled as a chip. Accepts `color`, `variant` and `size` like `Chip`.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `id` | `Key` | - | Unique key (required for selection and removal). |
| `textValue` | `string` | - | Plain-text label for typeahead and screen readers. |
