# Tecton → shadcn token mapping

> GENERATED by `packages/tecton-react/scripts/tokens-build.mts` from `packages/tecton-react/tokens/tecton.map.json` — do not edit.
> Edit the map (or `src/styles/tecton-tokens.css`) and run `pnpm --filter @tecton/react tokens:build`.

Tecton MUI v1.0 ships **dark only**; the dark column is the canonical Tecton value and the light
column is derived by tecton-mirror (Tecton ships no light theme; every light value is approximated. Strategy: `overrides` mirror the dark palette using Tecton's own tokens (page background = text-primary, foreground = bg-default, secondary/accent surfaces = action-primary-text, borders = outlined hover border, status surfaces = the status *muted* tokens with near-white text, chart accents unchanged). Any variable without an override falls back to OKLCH lightness inversion (L' = 1 - L, hue/chroma/alpha kept, clamped to sRGB).).

Confidence: **exact** = a Tecton token with the same meaning exists; **approximated** = the closest
Tecton token was chosen (see note); **derived** = computed, no Tecton source.

- **background** — text-primary (#f6f5f8) mirrored as the page surface; card/popover/sidebar are pure white to keep the paper-vs-page relationship.
- **foreground** — bg-default (#1d1c1f) mirrored as the text colour.
- **primary** — Pure inversion of #5d4d68 gives L 0.553, on which neither black nor white text reaches 4.5:1. A deeper shade of the same hue with light text (6.40:1) keeps the light-on-purple relationship. Applies to sidebar-primary too.
- **secondary** — action-primary-text (#e5e0eb) reused as the light secondary/accent surface; secondary-foreground is action-secondary-bg (#3a343e).
- **muted** — Light grey close to the mirrored filled-input surface; muted-foreground darkened from text-placeholder (#6a696c) to reach 4.5:1 on white.
- **destructive** — Between status-error-main (#c16e6c, 3.4:1 on white) and status-error-muted (#832d28); chosen to reach 4.5:1 as text on the page background.
- **border** — Tecton outlined-input hover/focus border (#cac5d2).
- **ring** — The brand focus pink (#ff52a8) only reaches 2.75:1 on the light page surface, so light mode uses a deeper shade of the same hue (#e0248c, ≥ 3:1 on white and on the page background).
- **chart-1** — Chart accents are mid-tone and stay identical in light mode (charts 1-5).
- **success** — status-success-muted (#217846) with near-white text; warning/info use status-warning-muted (#995b04) / status-info-muted (#3766c4) the same way.
- **neutral** — status-neutral-bright (#c8c7ca) with status-neutral-filled-bg (#2c2b2e) as text — the dark pair mirrored.

## Known deviations

Everything Tecton-specific must be expressed through the shadcn CSS variables above; generated
component files are never edited. The following Tecton behaviours cannot be reproduced that way and
are documented here (and, where the behaviour matters, addressed by a custom component instead):

- **Focus ring** — Vega renders focus as `ring-3 ring-ring/50` (3px, 50% alpha) while Tecton draws
  a solid 2px `#ff52a8` outline. The colour matches; width and opacity do not.
- **Button hover** — Vega darkens with `hover:bg-primary/80` while Tecton lightens the surface to
  `#74647f` (and text to `#ffffff`). Same for secondary (`#514659`) and tertiary/ghost (`#3a343e`).
- **Input variants** — shadcn has a single (outlined) input; Tecton has outlined, filled
  (`#28232c` surface) and textOnly variants. Filled/textOnly are provided by the custom
  `text-field` / `select-field` components.
- **Status colours** — Tecton's success/error/warning/info/neutral roles have no shadcn equivalent
  beyond `destructive`; they are exposed as the extra tokens above and used by custom components
  (`status-alert`, `chip`, `count-badge`).
