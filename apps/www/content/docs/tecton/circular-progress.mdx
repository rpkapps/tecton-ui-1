## Usage

```tsx
import { CircularProgress } from "@tecton/react/tecton/circular-progress"
```

```tsx
<CircularProgress aria-label="Resampling" value={64} showValue />
```

For a linear bar use [Progress](/docs/components/progress); for a plain loading icon use [Spinner](/docs/components/spinner).

## Sizes

`size` runs from `xs` (16 px) to `xl` (96 px); stroke and label scale with it.

## Value label

`showValue` renders the formatted value in the centre; children replace it with custom content. `min`, `max` and `format` set the scale and the text.

## Usage guidelines

### Use it when

- The progress belongs in a compact space: a card corner, a table cell, a tile, a KPI.
- The number matters as much as the arc: `showValue`, or children such as `7/12`.
- A ring, not an icon, is the right weight for an indeterminate wait inside a panel or a dialog.

### Not for

- a full-width determinate bar in the flow of a panel: use [Progress](/docs/components/progress)
- a small busy glyph inside a button or an input: use [Spinner](/docs/components/spinner)
- a segmented readout of risk, complexity or confidence: use [Meter](/docs/tecton/meter)

### Do

<DoList>

<Do>

Always pass `aria-label`; there is no visible label slot.

</Do>

<Do>

Size with `size="xs" | "sm" | "md" | "lg" | "xl"` (16 / 24 / 40 / 64 / 96 px): one prop drives the diameter, the stroke width and the centre type together.

</Do>

<Do>

Colour with `color="default" | "foreground" | "success" | "warning" | "error" | "info"`; `default` is the shared `progress` fill.

</Do>

<Do>

Give the scale with `min` and `max`, shape the text with `format` (`Intl.NumberFormatOptions`), or pass children for custom centre content.

</Do>

<Do>

Pass `value={null}`, not `value={0}`, while the total is unknown: the ring spins.

</Do>

</DoList>

### Don't

<Dont severity="CRITICAL" title="A ring with no accessible name">

<Wrong>

```tsx
<CircularProgress value={64} showValue />
```

</Wrong>

<Correct>

```tsx
<CircularProgress aria-label="Resampling" value={64} showValue />
```

</Correct>

The `svg` is `aria-hidden` and `role="progressbar"` takes no name from its contents, so without `aria-label` the ring is announced as an unnamed progress bar.

</Dont>

<Dont severity="HIGH" title="Sizing or colouring the ring with className">

<Wrong>

```tsx
<CircularProgress
  aria-label="Export"
  value={40}
  className="size-20 text-blue-600"
/>
```

</Wrong>

<Correct>

```tsx
<CircularProgress aria-label="Export" value={40} size="lg" color="default" />
```

</Correct>

`size` sets the diameter, the stroke and the centre label's type scale together; the stroke is drawn in the ring's own viewBox units and grows with the diameter, so overriding only the diameter turns the `md` ring into a heavy 7px stroke around a label still at `text-xs`, and `blue-600` is not a Tecton step — `cn` drops `text-progress` for a class that emits nothing and the stroke falls back to the inherited text colour.

</Dont>

<Dont severity="MEDIUM" title="showValue on an indeterminate ring">

<Wrong>

```tsx
<CircularProgress size="sm" value={null} showValue aria-label="Loading well logs" />
```

</Wrong>

<Correct>

```tsx
<div className="flex items-center gap-3 text-sm text-muted-foreground">
  <CircularProgress size="sm" value={null} aria-label="Loading well logs" />
  Loading well logs…
</div>
```

</Correct>

The centre label renders only for a determinate value, so the prop is ignored and the ring spins with an empty middle where the caption was expected.

</Dont>

{/* guidelines:end */}

## API Reference

### CircularProgress

A `div` with `role="progressbar"`; accepts `div` props.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `value` | `number \| null` | - | Required. `null` is indeterminate. |
| `min` / `max` | `number` | `0` / `100` | Scale of `value`. |
| `format` | `Intl.NumberFormatOptions` | percent | Format of the shown and announced value. |
| `locale` | `Intl.LocalesArgument` | runtime locale | Locale of the formatted value. |
| `size` | `"xs" \| "sm" \| "md" \| "lg" \| "xl"` | `"md"` | Diameter 16 / 24 / 40 / 64 / 96 px. |
| `color` | `"default" \| "foreground" \| "success" \| "warning" \| "error" \| "info"` | `"default"` | Ring colour. |
| `showValue` | `boolean` | `false` | Show the formatted value in the centre. |
| `children` | `ReactNode` | - | Custom centre content; overrides `showValue`. |
| `aria-label` | `string` | - | Required without a visible label. |
