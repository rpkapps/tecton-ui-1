title: Tecton components
description: "Patterns that exist only in the Tecton design system: chips, tree views, meters, panels and the application shell."
---

Most Tecton semantics are carried by the [components](/docs/components) themselves, as
variants: the severity and surface of an alert are `Alert` `variant` and `appearance`, a
chip's colours and outlined look are `Badge` `variant` and `appearance`, the three field
surfaces are `Input`, `Textarea` and `SelectTrigger` `variant`, the divider emphases are
`Separator` `emphasis`, and the floating action button is a `Button` recipe. Each
component page documents its Tecton variants.

What lives here are the patterns with no general-purpose counterpart at all — a
selectable tag group, a segmented meter, a tree view, an application shell. They are
built from the same primitives, follow the same conventions, and are used the same way.

All of them are exported from `@tecton/react/tecton/<name>`.

| Component | Description |
| --- | --- |
| [Action Bar](/docs/tecton/action-bar) | Transient bar for a selection or unsaved changes, with collapsing actions. |
| [App Finder](/docs/tecton/app-finder) | Application switcher for the shell header. |
| [App Shell](/docs/tecton/app-shell) | Application frame: top bar, sidebar, main area and aside. |
| [Background](/docs/tecton/background) | Eleven decorative background effects from oil and gas imagery, themed in both modes. |
| [Canvas](/docs/tecton/canvas) | Full-bleed work surface with floating toolbars, legend and overlays. |
| [Chip](/docs/tecton/chip) | Selectable and removable tags in a group; static labels are Badges. |
| [Circular Progress](/docs/tecton/circular-progress) | Progress ring with value label or indeterminate spinner. |
| [Color Swatch](/docs/tecton/color-swatch) | Colour preview with optional label and value. |
| [Copy Button](/docs/tecton/copy-button) | Copies a value to the clipboard with check-mark feedback. |
| [Count Badge](/docs/tecton/count-badge) | Count or dot anchored to the corner of an avatar or icon button. |
| [Link](/docs/tecton/link) | Inline text link with variants and an external-link icon. |
| [Meter](/docs/tecton/meter) | Segmented gauge for risk, complexity and confidence. |
| [Overflow](/docs/tecton/overflow) | Toolbar row that collapses labels, then items into a More menu, when narrow. |
| [Page Header](/docs/tecton/page-header) | Page title block with eyebrow, description, section tabs and actions. |
| [Panel](/docs/tecton/panel) | Titled application surface with scrolling body and pinned footer. |
| [Portal Provider](/docs/tecton/portal) | Chooses the element Tecton overlays portal into, for pages with several isolated React roots. |
| [Shell Actions](/docs/tecton/shell-actions) | Global action cluster: command palette trigger, icon actions, overflow and user menu. |
| [Shortcuts](/docs/tecton/shortcuts) | Keyboard shortcut registry: the host listens, applications register, the shell lists. |
| [Stat](/docs/tecton/stat) | KPI readout with mono value, unit and trend delta. |
| [Tree View](/docs/tecton/tree-view) | Hierarchical tree with folder / item rows, states and adornments. |

## Renamed from earlier Tecton releases

| Former Tecton component | Now |
| --- | --- |
| StatusAlert | [Alert](/docs/components/alert) with `variant` (severity) and `appearance` |
| Chip (static label) | [Badge](/docs/components/badge) with `variant`, `appearance` and `size` |
| Divider | [Separator](/docs/components/separator) with `emphasis` |
| FAB | [Button](/docs/components/button) with `rounded-full shadow-md` |
| TextField / SelectField | [Input](/docs/components/input), [Textarea](/docs/components/textarea) and [Select](/docs/components/select) with `variant`, inside a `Field` |
