## Which one?

Tecton applications use **TanStack Form**: it is headless, framework-agnostic and shares the TanStack conventions of the router and table already in use. The guide covers every form control (input, textarea, select, checkbox, radio group, switch) and array fields.

`Field` owns no form state, so any headless library works — React Hook Form included. Whatever you pick, the wiring is the same and only the control props differ: Tecton's controlled inputs use `isSelected` / `onChange`, `selectedKey` / `onSelectionChange` and `isInvalid`, which is what [Working with different field types](/docs/forms/tanstack-form#working-with-different-field-types) lists per control.
