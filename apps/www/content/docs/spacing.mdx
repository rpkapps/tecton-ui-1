## Spacing

Tecton's spacing scale is 4px-based and coincides with Tailwind's default spacing (`--spacing` is a quarter of `--tecton-rem`, which is `1rem` unless the page [scales Tecton](#scaling-tecton)), so the usual Tailwind steps apply:

| Tecton | px | Tailwind |
| --- | --- | --- |
| space-0 | 0 | `0` |
| space-25 | 2 | `0.5` |
| space-50 | 4 | `1` |
| space-75 | 6 | `1.5` |
| space-100 | 8 | `2` |
| space-150 | 12 | `3` |
| space-200 | 16 | `4` |
| space-250 | 20 | `5` |
| space-300 | 24 | `6` |
| space-400 | 32 | `8` |
| space-500 | 40 | `10` |
| space-600 | 48 | `12` |
| space-700 | 56 | `14` |
| space-800 | 64 | `16` |
| space-900 | 72 | `18` |
| space-1000 | 80 | `20` |
| space-1200 | 96 | `24` |
| space-1400 | 112 | `28` |
| space-1600 | 128 | `32` |
| space-1800 | 144 | `36` |

The values are also exposed as `--tecton-space-*` variables for non-Tailwind consumers.

## Scaling Tecton

Tecton's rem-based sizes (the spacing steps and the `text-*` sizes) are multiples of one variable, `--tecton-rem`, which defaults to `1rem`. Radii and borders are in pixels and do not take part. The `max-w-*` container widths (`max-w-md`…) stay plain `rem`: Tailwind also uses them for container queries (`@md:`), where a variable is not allowed.

A page that has to change its root font size for something else, such as an Angular micro-frontend built on PrimeNG's 14px base inside a Tecton shell, sets the root and gives Tecton its 16px back in the same place:

```css title="shell.css"
html {
  font-size: 87.5%; /* 14px: what PrimeNG is designed for */
}
:root {
  --tecton-rem: calc(1rem / 0.875); /* Tecton stays at 16px */
}
```

Both stay relative to the browser's default font size, so a user who enlarges it enlarges both. The variable inherits, so a Tecton micro-frontend mounted in that shell follows it with no setting of its own.

Write sizes the same way in your own code: a Tailwind step (`p-4`, `h-8`, `text-sm`) or `--spacing(n)` in an arbitrary value (`w-[--spacing(104)]`, `text-[--spacing(2.5)]`) follows `--tecton-rem`, a literal `rem` (`w-[26rem]`, `style={{ width: "2rem" }}`) does not.

## Radius

Tecton's default corner radius is **4px**; the scale is not a multiple of a single base, so the shadcn radius variables are set explicitly instead of being derived from `--radius`:

| Tecton | px | shadcn / Tailwind |
| --- | --- | --- |
| radius-0 | 0 | `rounded-none` |
| radius-25 | 2 | `--radius-sm` → `rounded-sm` |
| radius-50 | 4 | `--radius`, `--radius-md` → `rounded-md` (default) |
| radius-100 | 8 | `--radius-lg` → `rounded-lg` |
| radius-150 | 12 | `--radius-xl` → `rounded-xl` |
| radius-200 | 16 | `--radius-2xl` → `rounded-2xl` |
| radius-round | 1000 | `rounded-full` |
