## Usage guidelines

### Use it when

- A setting that takes effect the moment it is flipped, with no submit step.
- An on/off preference in a settings panel or a choice card.
- The two states are opposites of one thing, not two options to choose between.

### Not for

- a term the user ticks as part of submitting a form: use [Checkbox](/docs/components/checkbox)
- the label, description and layout around the control: use [Field](/docs/components/field)
- a value picked from a continuous range: use [Slider](/docs/components/slider)

### Do

<DoList>

<Do>

Control it with `checked` and `onCheckedChange(checked: boolean)`, or leave it uncontrolled with `defaultChecked`.

</Do>

<Do>

Pick the scale with `size="sm" | "default"`; the thumb travel is matched to each.

</Do>

<Do>

Give it an `id` and point a `FieldLabel htmlFor` at it inside a `Field orientation="horizontal"`, with `FieldContent` for the description.

</Do>

<Do>

Disable with `disabled` and put `data-disabled` on the `Field`; for an invalid value set `aria-invalid` on the `Switch` and `data-invalid` on the `Field`.

</Do>

<Do>

For a choice card, wrap the whole `Field` in a `FieldLabel` so the card surface is the hit target.

</Do>

</DoList>

### Don't

<Dont severity="CRITICAL" title="React Aria selection props">

<Wrong>

```tsx
<Switch id="two-factor" isSelected={enabled} onChange={setEnabled} />
```

</Wrong>

<Correct>

```tsx
<Switch id="two-factor" checked={enabled} onCheckedChange={setEnabled} />
```

</Correct>

`isSelected` is not a prop and `onChange` receives a DOM event, not the boolean, so the switch runs uncontrolled and `setEnabled` is handed an event object.

</Dont>

<Dont severity="HIGH" title="Disabling the switch with isDisabled">

<Wrong>

```tsx
<Field orientation="horizontal">
  <Switch id="sync" isDisabled />
  <FieldLabel htmlFor="sync">Sync across devices</FieldLabel>
</Field>
```

</Wrong>

<Correct>

```tsx
<Field orientation="horizontal" data-disabled>
  <Switch id="sync" disabled />
  <FieldLabel htmlFor="sync">Sync across devices</FieldLabel>
</Field>
```

</Correct>

The switch reads `disabled`; `isDisabled` is not a prop, so the switch stays focusable and operable and neither it nor the label dims.

</Dont>

<Dont severity="MEDIUM" title="Sizing the switch with height and width">

<Wrong>

```tsx
<Switch id="compact" className="h-6 w-11" />
```

</Wrong>

<Correct>

```tsx
<Switch id="compact" size="default" />
```

</Correct>

The track is sized by `data-[size=…]` and the thumb's `translate-x` is matched to each size, so a `className` size widens the track while the thumb still stops where the old one ended.

</Dont>
