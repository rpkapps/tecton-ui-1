## Usage

```tsx
import { Divider } from "@tecton/react/tecton/divider"
```

```tsx
<Divider emphasis="subtle" />
<Divider>or</Divider>
<Divider orientation="vertical" />
```

<Callout>
  shadcn has a single `--border` colour. Tecton distinguishes three border emphases, which are extra tokens in the theme; `Divider` is the [Separator](/docs/components/separator) with those tokens applied.
</Callout>

## Emphasis

Use the `emphasis` prop. The levels map to the Tecton `--border-subtle`, `--border` and `--border-strong` tokens.

## API Reference

### Divider

Accepts all `Separator` props.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `emphasis` | `"subtle" \| "medium" \| "strong"` | "medium" | Border colour token. |
| `orientation` | `"horizontal" \| "vertical"` | "horizontal" | Direction. |
| `children` | `ReactNode` | - | Inline label (horizontal only). |
