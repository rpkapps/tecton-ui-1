## Usage

```tsx
import { CopyButton } from "@tecton/react/tecton/copy-button"
```

```tsx
<CopyButton value="34/10-A-12" />
```

The outcome is announced to screen readers ("Copied" or "Copy failed"), and an icon-only button takes that text as its name while the state lasts.

## Labelled

With children the button is labelled and its size defaults to `sm` instead of `icon-sm`. Every `Button` variant works.

<ComponentPreview name="copy-button-labelled" />

## Feedback

`onCopied` runs after a successful copy and `timeout` sets how long the check shows. When the clipboard refuses the write (insecure context, denied permission) the button shows a cross instead and `onError` receives the error.

<ComponentPreview name="copy-button-feedback" />

```tsx
<CopyButton value={wellId} onError={() => toast.error("Could not copy the well ID")} />
```

## Usage guidelines

### Use it when

- A value on screen is meant to be pasted elsewhere: an identifier, a URL, a snippet.
- The user needs the copy confirmed in place, without a toast or a dialog.
- The control sits next to the value, usually as a quiet icon button.

### Not for

- any action on a value other than copying it: use [Button](/docs/components/button)
- a confirmation that appears away from the control: use [toast](/docs/components/sonner)

### Do

<DoList>

<Do>

Pass the text as `value` and let the component own the click handler.

</Do>

<Do>

Leave it icon-only for a quiet affordance, or pass text `children` for a prominent labelled one.

</Do>

<Do>

Set weight with `variant` (it defaults to `ghost`) and hold time with `timeout`.

</Do>

<Do>

React to a successful copy with `onCopied`, and to a refused one (insecure context, denied permission) with `onError`, not by wrapping the button in your own handler.

</Do>

<Do>

Let the component name itself: with no children it sets `aria-label` to "Copy", then "Copied" or "Copy failed"; either outcome is also announced through a polite live region.

</Do>

</DoList>

### Don't

<Dont severity="HIGH" title="A Button with a hand-written clipboard handler">

<Wrong>

```tsx
<Button variant="ghost" size="icon-sm" onClick={() => navigator.clipboard.writeText(well.id)}>
  <CopyIcon />
</Button>
```

</Wrong>

<Correct>

```tsx
<CopyButton value={well.id} />
```

</Correct>

The hand-rolled version drops everything the component adds: the copied state and check-mark swap, the `aria-label` that flips to "Copied", the announcement, and the "Copy failed" state for a denied or insecure clipboard, which otherwise rejects unhandled.

</Dont>

<Dont severity="HIGH" title="An onClick handler passed to CopyButton">

<Wrong>

```tsx
<CopyButton value={well.id} onClick={() => track("copy")} />
```

</Wrong>

<Correct>

```tsx
<CopyButton value={well.id} onCopied={() => track("copy")} />
```

</Correct>

`CopyButton` omits `onClick` from its props and spreads the remaining props after its own, so an `onClick` forced through replaces the clipboard handler and the button quietly stops copying.

</Dont>

<Dont severity="HIGH" title="Supplying the icon as the child">

<Wrong>

```tsx
<CopyButton value={well.id}><CopyIcon /></CopyButton>
```

</Wrong>

<Correct>

```tsx
<CopyButton value={well.id} />
```

</Correct>

The component already renders `CopyIcon` or `CheckIcon` itself, so a child icon is drawn twice, switches the size default from `icon-sm` to `sm`, and suppresses the automatic accessible name because children are now present.

</Dont>

{/* guidelines:end */}

## API Reference

### CopyButton

A `Button` with clipboard behaviour; accepts all `Button` props except `onClick`. It carries `data-copied` or `data-error` while that state shows.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `value` | `string` | - | Text written to the clipboard. |
| `timeout` | `number` | `2000` | Milliseconds the check or cross is shown. |
| `onCopied` | `(value: string) => void` | - | Called after a successful copy. |
| `onError` | `(error: unknown) => void` | - | Called with the clipboard's error when the copy fails. |
| `variant` | `ButtonProps["variant"]` | `"ghost"` | Button variant. |
| `size` | `ButtonProps["size"]` | `"icon-sm"`, or `"sm"` with children | Button size. |
| `children` | `ReactNode` | - | Label. |
