## Usage

```tsx
import { Link, LinkButton } from "@tecton/react/tecton/link"
```

```tsx
<Link href="/wells/34-10-A-12" variant="primary">
  34/10-A-12
</Link>
<LinkButton href="/wells" variant="outline">
  All wells
</LinkButton>
```

`Link` is a real anchor for navigation; `Button variant="link"` is a button that only looks like one. By default a link inherits the surrounding font size; `size` sets it.

## Variants

`subtle` is always underlined; the others underline on hover.

## External

`external` opens the link in a new tab, adds `noreferrer noopener` to `rel` and appends an icon. A `target` you pass wins, and a `rel` you pass is added.

## Routing

With `navigate` (and optionally `useHref`) on the [TectonProvider](/docs/tecton/provider#router), a plain click on a same-origin link calls `navigate(href, navigateOptions)` instead of loading the page. Modifier and middle clicks, `target="_blank"`, `download` and other origins are left to the browser.

```tsx
<Link href="/wells" navigateOptions={{ replace: true }}>
  Wells
</Link>
```

## Usage guidelines

### Use it when

- A word or phrase inside running text navigates somewhere: a well, a report, an external register (`Link`).
- A navigation target should look like a button: "Open well", "Back to wells" (`LinkButton`).
- The destination leaves the application and needs the external marker.

### Not for

- something that happens in place instead of navigation: use [Button](/docs/components/button)
- the trail of parent pages above a page title: use [Breadcrumb](/docs/components/breadcrumb)

### Do

<DoList>

<Do>

Always pass `href`: both render a real `<a>`, so new-tab, copy-address and the status bar work.

</Do>

<Do>

Choose colour with `variant="default" | "primary" | "muted" | "subtle"`; leave `size="inherit"` inside prose. `LinkButton` takes the `Button` `variant` and `size`.

</Do>

<Do>

Mount `TectonProvider` with the router's `navigate` and `useHref`: plain clicks then navigate without a page load, ⌘/Ctrl/Shift-clicks and `target="_blank"` still go to the browser. Router options go in `navigateOptions`.

</Do>

<Do>

Reach outside the app with `external`, and disable with `disabled` (no `href`, not focusable, `aria-disabled`).

</Do>

<Do>

Link text names the destination ("34/10-A-12 daily report"), never "click here", "read more" or a bare URL.

</Do>

<Do>

Add an accessible label only to an icon-only link; a text link is already named by its visible text.

</Do>

</DoList>

### Don't

<Dont severity="HIGH" title="A Link or LinkButton used to run an action">

<Wrong>

```tsx
<Link onClick={() => archive(well.id)}>Archive</Link>
```

</Wrong>

<Correct>

```tsx
<Button variant="link" onClick={() => archive(well.id)}>Archive</Button>
```

</Correct>

Without `href` the anchor is not a link at all: it is not focusable, has no role and promises navigation it cannot do.

</Dont>

<Dont severity="HIGH" title="An anchor nested inside a Button">

<Wrong>

```tsx
<Button variant="secondary"><a href="/wells/34-10-A-12">Open well</a></Button>
```

</Wrong>

<Correct>

```tsx
<LinkButton variant="secondary" href="/wells/34-10-A-12">Open well</LinkButton>
```

</Correct>

A link inside a `button` is invalid markup and is announced and activated as a button; `LinkButton` is the anchor with the button styles.

</Dont>

<Dont severity="HIGH" title="Hand-built target, rel and external icon">

<Wrong>

```tsx
<Link href="https://factpages.sodir.no" target="_blank">
  Sodir FactPages <ExternalLinkIcon />
</Link>
```

</Wrong>

<Correct>

```tsx
<Link href="https://factpages.sodir.no" external>Sodir FactPages</Link>
```

</Correct>

`external` sets `target="_blank"` and `rel="noreferrer noopener"` together and appends the icon at the variant's `0.85em` size; a `rel` you pass as well (`nofollow`) is added to those two. `target="_blank"` alone leaves the opened page a handle on `window.opener`.

</Dont>

<Dont severity="MEDIUM" title="Colouring the link with className">

<Wrong>

```tsx
<Link href="/wells/34-10-A-12" className="text-blue-600 underline">34/10-A-12</Link>
```

</Wrong>

<Correct>

```tsx
<Link href="/wells/34-10-A-12" variant="primary">34/10-A-12</Link>
```

</Correct>

The variant owns the colour and when the underline appears, and Tailwind's stock palette is reset here, so `text-blue-600` emits no CSS.

</Dont>

## API Reference

### Link

Renders an `a` and accepts its attributes.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `href` | `string` | - | Destination; mapped by the provider's `useHref` for the rendered anchor. |
| `variant` | `"default" \| "primary" \| "muted" \| "subtle"` | `"default"` | Colour and underline. |
| `size` | `"inherit" \| "sm" \| "md" \| "lg"` | `"inherit"` | Font size. |
| `external` | `boolean` | `false` | New tab, safe `rel`, external icon. |
| `disabled` | `boolean` | `false` | Drops `href` (no navigation, not focusable) and sets `aria-disabled`. |
| `navigateOptions` | `unknown` | - | Second argument of the provider's `navigate`. |
| `onClick` | `(event: MouseEvent) => void` | - | Runs before navigation; `event.preventDefault()` cancels it. |
| `render` | `ReactElement \| (props, state) => ReactElement` | - | Render another anchor element, such as a router's link, with the link props merged in. |

A disabled link carries `data-disabled`.

### LinkButton

The `href`, `disabled`, `navigateOptions`, `onClick` and `render` props of `Link`, plus:

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `variant` | `"default" \| "outline" \| "secondary" \| "ghost" \| "destructive" \| "link"` | `"default"` | Button variant. |
| `size` | `"default" \| "xs" \| "sm" \| "lg" \| "icon" \| "icon-xs" \| "icon-sm" \| "icon-lg"` | `"default"` | Button size. |
