## Usage

```tsx
import {
  TreeView,
  TreeViewItem,
  TreeViewItemContent,
  TreeViewAction,
  TreeViewVisibilityToggle,
  TreeViewCollection,
} from "@tecton/react/tecton/tree-view"
```

```tsx
<TreeView aria-label="Project" selectionMode="single" defaultExpanded={["wells"]}>
  <TreeViewItem value="wells">
    <TreeViewItemContent kind="folder">Wells</TreeViewItemContent>
    <TreeViewItem value="a12">
      <TreeViewItemContent>34/10-A-12</TreeViewItemContent>
    </TreeViewItem>
  </TreeViewItem>
</TreeView>
```

<Callout>
  shadcn has no tree component; the closest is the file tree built from `Collapsible` and `Sidebar`. `TreeView` is an ARIA treegrid with arrow-key navigation, type-ahead, selection and expansion, plus the Tecton row anatomy.
</Callout>

## Nested

Nest `TreeViewItem`s inside each other. For data, pass `items` to `TreeView` with a render function, and render each node's children with `TreeViewCollection`; indentation follows the depth. Rows re-render with their parent, so a row that reads state kept outside `items` (a hidden set) updates without anything else to declare.

## States

`selectionMode` (`"none"`, `"single"`, `"multiple"`) with `value` / `defaultValue` / `onValueChange`, and `expanded` / `defaultExpanded` / `onExpandedChange`, all string arrays of row `value`s. `disabled` on a `TreeViewItem` takes it out of selection, expansion and arrow-key movement; `hidden` renders the dimmed *hidden* state from the design system (the row stays in the tree).

<ComponentPreview name="tree-view-states" />

## Adornments

`TreeViewItemContent` has slots for a `colorTag` (a [ColorSwatch](/docs/tecton/color-swatch)), a `suffix` (a [Badge](/docs/components/badge)) and an `endAdornment` such as `TreeViewVisibilityToggle` or `TreeViewAction`. Arrow keys move from a row into its controls; clicking a control neither selects nor expands the row.

<ComponentPreview name="tree-view-adornments" />

`TreeViewVisibilityToggle` is a toggle button: its name is always "Hide" and `aria-pressed` carries the state (pressed while the row is hidden), so a screen reader announces "Hide Faults, toggle button, pressed" rather than a name that flips between "Hide" and "Show". Inside `TreeViewItemContent` the name is completed with the row's label; when the label is not plain text, pass `name`. `TreeViewAction` has no name of its own: give it an `aria-label`.

## Styling

Rows (`data-slot="tree-view-item"`, a `group/tree-item`) expose presence attributes: `data-selected`, `data-expanded`, `data-disabled` and `data-hidden`, plus `data-level` (depth, from 1). Hover, press and focus have no attributes: use `:hover`, `:active`, `:focus-visible` and `:focus-within`. To reveal a row control on hover:

```tsx
<TreeViewAction
  aria-label="Actions"
  className="opacity-0 group-hover/tree-item:opacity-100 group-focus-within/tree-item:opacity-100 group-data-selected/tree-item:opacity-100"
/>
```

Arrow keys follow the [TectonProvider](/docs/tecton/provider) direction: in a right-to-left tree, Left expands and Right collapses.

## Usage guidelines

### Use it when

- A hierarchy is browsed rather than read: a project tree, a field and well inventory, a layer list.
- Rows carry more than a label: selection, disabled, hidden, a colour, a count, a per-row menu.
- Arrow-key navigation, expansion and type-ahead have to work across the whole structure.

### Not for

- stacked sections that expand, with no parent and child structure: use [Accordion](/docs/components/accordion)
- a flat list of rows with media, a title and actions: use [Item](/docs/components/item)

### Do

<DoList>

<Do>

Give `TreeView` an `aria-label` and every `TreeViewItem` a unique `value`; add `textValue` when the row label is not plain text.

</Do>

<Do>

Put `TreeViewItemContent` first inside each `TreeViewItem`, then the child `TreeViewItem`s — or `items` on `TreeView` and a `TreeViewCollection` per node for data.

</Do>

<Do>

Drive state with string arrays: `selectionMode`, `value` / `defaultValue` / `onValueChange` and `expanded` / `defaultExpanded` / `onExpandedChange`; mark rows with `disabled` and `hidden` on `TreeViewItem`.

</Do>

<Do>

Hang the extras on `TreeViewItemContent`: `colorTag`, `suffix`, `endAdornment` (`TreeViewVisibilityToggle` with `visible` / `onVisibleChange`, `TreeViewAction` with `onClick`).

</Do>

<Do>

Style rows from the presence attributes `data-selected`, `data-expanded`, `data-disabled`, `data-hidden` and from `:hover` / `:focus-visible` (`group-hover/tree-item:opacity-100`).

</Do>

<Do>

The tree opens on the branches the user came for (active field, selected well's parents), not a column of closed folders (`defaultExpandedKeys`).

</Do>

</DoList>

### Don't

<Dont severity="CRITICAL" title="A tree built from nested Collapsibles">

<Wrong>

```tsx
<Collapsible>
  <CollapsibleTrigger>Wells</CollapsibleTrigger>
  <CollapsibleContent className="ps-4">
    <Collapsible>
      <CollapsibleTrigger>34/10-A-12</CollapsibleTrigger>
      <CollapsibleContent className="ps-4">Completions</CollapsibleContent>
    </Collapsible>
  </CollapsibleContent>
</Collapsible>
```

</Wrong>

<Correct>

```tsx
<TreeView aria-label="Project" selectionMode="single" defaultExpanded={["wells"]}>
  <TreeViewItem value="wells">
    <TreeViewItemContent kind="folder">Wells</TreeViewItemContent>
    <TreeViewItem value="a12">
      <TreeViewItemContent>34/10-A-12</TreeViewItemContent>
    </TreeViewItem>
  </TreeViewItem>
</TreeView>
```

</Correct>

Each `Collapsible` is its own widget, so the result is a pile of buttons with no `role="treegrid"`, no arrow-key or type-ahead movement between rows and no selection.

</Dont>

<Dont severity="HIGH" title="Indenting rows with padding classes">

<Wrong>

```tsx
<TreeViewItemContent className="ps-8">34/10-A-12</TreeViewItemContent>
```

</Wrong>

<Correct>

```tsx
<TreeViewItem value="wells">
  <TreeViewItemContent kind="folder">Wells</TreeViewItemContent>
  <TreeViewItem value="a12">
    <TreeViewItemContent>34/10-A-12</TreeViewItemContent>
  </TreeViewItem>
</TreeViewItem>
```

</Correct>

`TreeViewItemContent` writes `paddingInlineStart` as an inline style from the row's depth, which no `className` can outrank, so the nesting sets the indent and `ps-8` is dead weight.

</Dont>

<Dont severity="MEDIUM" title="Styling rows on hover or focus attributes">

<Wrong>

```tsx
<TreeViewAction className="opacity-0 group-data-hovered/tree-item:opacity-100" aria-label="Actions" />
```

</Wrong>

<Correct>

```tsx
<TreeViewAction className="opacity-0 group-hover/tree-item:opacity-100 group-focus-within/tree-item:opacity-100" aria-label="Actions" />
```

</Correct>

Rows expose no hover, press or focus attributes: use `:hover`, `:active`, `:focus-visible` and `:focus-within`, and the presence attributes for state.

</Dont>

## API Reference

### TreeView

The treegrid. Accepts `div` attributes (`className`, `aria-label`…).

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `aria-label` | `string` | - | Accessible name of the tree. |
| `selectionMode` | `"none" \| "single" \| "multiple"` | "none" | Row selection. |
| `value` | `string[]` | - | Selected rows (controlled). |
| `defaultValue` | `string[]` | - | Initially selected rows. |
| `onValueChange` | `(value: string[]) => void` | - | Called with every selected row's `value`. |
| `expanded` | `string[]` | - | Expanded rows (controlled). |
| `defaultExpanded` | `string[]` | - | Initially expanded rows. |
| `onExpandedChange` | `(expanded: string[]) => void` | - | Called with every expanded row's `value`. |
| `items` | `Iterable<T>` | - | Data for the top-level rows; `children` is then `(item: T) => ReactNode`. |

### TreeViewItem

One row. Put a `TreeViewItemContent` first, then child `TreeViewItem`s or a `TreeViewCollection`.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `value` | `string` | - | The row's identity, unique in the tree. |
| `textValue` | `string` | content text | Plain-text name for type-ahead; needed when the content is not plain text. |
| `disabled` | `boolean` | false | Not selectable, not expandable, skipped by the arrow keys. |
| `hidden` | `boolean` | false | Dimmed hidden state (`data-hidden`); the row stays visible. |

### TreeViewCollection

The child rows of a `TreeViewItem`, rendered from data.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `items` | `Iterable<T>` | - | Data for the child rows. |
| `children` | `(item: T) => ReactNode` | - | Renders one `TreeViewItem` per entry. |

### TreeViewItemContent

Row layout: chevron, icon, colour tag, label, suffix and end adornment.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `kind` | `"folder" \| "item"` | "item" | Folder icon or a small dot. |
| `icon` | `ReactNode` | - | Custom leading icon. |
| `colorTag` | `ReactNode` | - | 12 px colour tag after the icon. |
| `suffix` | `ReactNode` | - | Content after the label. |
| `endAdornment` | `ReactNode` | - | Trailing actions. |

### TreeViewAction

24 px icon button for row actions; renders a vertical ellipsis by default. Give it an `aria-label`.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `aria-label` | `string` | - | Accessible name ("Actions for Faults"). |
| `onClick` | `() => void` | - | Called on pointer, Enter or Space activation. |
| `disabled` | `boolean` | false | Disables the button. |
| `children` | `ReactNode` | `<MoreVerticalIcon />` | Custom icon. |

### TreeViewVisibilityToggle

Eye / eye-off toggle built on `TreeViewAction`. Its accessible name is always "Hide" followed by the row's label (or by `name`), and `aria-pressed` is true while the row is hidden.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `visible` | `boolean` | true | Current visibility; the toggle is pressed when it is `false`. |
| `onVisibleChange` | `(visible: boolean) => void` | - | Called with the next value. |
| `name` | `string` | - | What the toggle hides, for the name `"Hide {name}"`. Without it (and without `aria-label` / `aria-labelledby`) the name is "Hide" plus the row's label inside `TreeViewItemContent`. |
| `disabled` | `boolean` | false | Disables the toggle. |
