Tecton UI uses **two icon libraries**:

- **Lucide** (`lucide-react`) for every general-purpose glyph. The generated components use it internally (chevrons, check marks, close buttons…).
- **Tecton icons** (`@tecton/react/icons`) for the 18 domain glyphs Lucide has no answer for (wells, horizons, seismic, drill bits…). Each is a React component with the Lucide signature (`size`, `strokeWidth`, `className`, SVG props) plus `variant="outlined" | "filled"`.

```tsx
import { SearchIcon } from "lucide-react"
import { SeismicIcon, WellIcon } from "@tecton/react/icons"

<Button>
  <WellIcon data-icon="inline-start" /> New well
</Button>
<SeismicIcon variant="filled" size={20} />
```

## Optical sizing

The Tecton export draws every glyph on a 16-unit grid with a margin baked in, so it looks smaller than a Lucide icon of the same size. `icons:build` crops the `viewBox` by up to one unit per side (`0 0 16 16` → `1 1 14 14`, about 1.14× larger), clamped per icon so nothing is clipped; both variants share one crop, so toggling `variant` never shifts the glyph. Path data is never touched.

## Regenerating

The glyphs come from the Tecton icon export vendored in `packages/tecton-react/icons-src/tecton/`, trimmed to the entries marked `domain: true` in `icons/icons.json`. Replace the export and rebuild:

```bash
pnpm --filter @tecton/react icons:build              # regenerates src/icons/*
pnpm --filter @tecton/react icons:build -- --check   # CI drift guard
```

A loose SVG in `icons-src/outlined/` or `icons-src/filled/` overrides that variant of a definition.
