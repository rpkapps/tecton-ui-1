## Cursor

Tailwind v4 [switched](https://tailwindcss.com/docs/upgrade-guide#buttons-use-the-default-cursor) from `cursor: pointer` to `cursor: default` for the button component.

If you want to keep the `cursor: pointer` behavior, add the following code to your CSS file:

```css showLineNumbers title="globals.css"
@layer base {
  button:not(:disabled),
  [role="button"]:not(:disabled) {
    cursor: pointer;
  }
}
```

## As Link

You can use the `buttonVariants` helper to make a link look like a button.

**Do not use `<Button>` for links.** The React Aria `Button` component always applies `role="button"`, which overrides the semantic link role on `<a>` elements. Use `buttonVariants` with a plain `<a>` tag instead.

## Floating action button

A Tecton FAB is a `Button` recipe: `className="h-10 rounded-full shadow-md"` for the extended form and `size="icon" className="rounded-full shadow-md"` (with an `aria-label`) for the round one. Any `variant` works; `default`, `secondary`, `ghost` and `outline` correspond to the design system's primary, secondary, tertiary and outlined FABs.

## Usage guidelines

### Use it when

- Something happens in place: submit, open a dialog, run an action, trigger a menu.
- A real `button` element is the right semantics, and one of the action weights fits: `default`, `secondary`, `outline`, `ghost`, `destructive`, `link`.

### Not for

- a link inside a sentence or a paragraph: use [Link](/docs/tecton/link)
- several related actions behind one control: use [DropdownMenu](/docs/components/dropdown-menu)
- copying a value to the clipboard with feedback: use [CopyButton](/docs/tecton/copy-button)

### Do

<DoList>

<Do>

Handle presses with `onPress` and disable with `isDisabled`; React Aria has no `disabled` contract.

</Do>

<Do>

Pick weight with `variant` and the box with `size`; keep `className` for layout only (`w-full`, `ms-auto`).

</Do>

<Do>

Mark icons with `data-icon="inline-start" | "inline-end"` so the padding adjusts, and give icon-only buttons an `aria-label`.

</Do>

<Do>

Navigate with `LinkButton` from this module, or with `buttonVariants()` on a plain `a`.

</Do>

<Do>

Show work with a `Spinner` child plus `isDisabled`; a FAB is the documented `rounded-full shadow-md` recipe.

</Do>

</DoList>

### Don't

<Dont severity="CRITICAL" title="An anchor nested inside a React Aria Button">

<Wrong>

```tsx
<Button variant="secondary" size="sm" asChild>
  <a href="/wells/34-10-A-12">Open well</a>
</Button>
```

</Wrong>

<Correct>

```tsx
<LinkButton variant="secondary" size="sm" href="/wells/34-10-A-12">Open well</LinkButton>
```

</Correct>

React Aria's `Button` has no `asChild`, so the prop is dropped and the anchor is nested inside a `button` that forces `role="button"`: invalid markup, and the link is announced and activated as a button.

</Dont>

<Dont severity="HIGH" title="The disabled prop instead of isDisabled">

<Wrong>

```tsx
<Button disabled onPress={submit}>Save</Button>
```

</Wrong>

<Correct>

```tsx
<Button isDisabled onPress={submit}>Save</Button>
```

</Correct>

`disabled` is not part of React Aria's button props, so it never reaches the DOM element and the button stays focusable, hoverable and pressable.

</Dont>

<Dont severity="HIGH" title="Sizing and colouring a Button with className">

<Wrong>

```tsx
<Button className="h-12 bg-blue-600 px-6 text-white">Assign</Button>
```

</Wrong>

<Correct>

```tsx
<Button size="lg">Assign</Button>
```

</Correct>

The variant owns colour, shape, size and padding, and Tailwind's stock palette is reset here, so `bg-blue-600` emits no CSS while the hand-set height breaks the `size` scale; `@tecton/eslint-config` reports both.

</Dont>

<Dont severity="MEDIUM" title="onClick instead of the onPress handler">

<Wrong>

```tsx
<Button onClick={() => setOpen(true)}>Open</Button>
```

</Wrong>

<Correct>

```tsx
<Button onPress={() => setOpen(true)}>Open</Button>
```

</Correct>

`onClick` survives only as React Aria's deprecated compatibility alias: it is handed a synthetic mouse event with no `pointerType`, so keyboard and touch activations are indistinguishable from a click.

</Dont>

{/* guidelines:end */}

## API Reference

### Button

The `Button` component is a wrapper around the `button` element that adds a variety of styles and functionality.

| Prop      | Type                                                                                 | Default     |
| --------- | ------------------------------------------------------------------------------------ | ----------- |
| `variant` | `"default" \| "outline" \| "ghost" \| "destructive" \| "secondary" \| "link"`        | `"default"` |
| `size`    | `"default" \| "xs" \| "sm" \| "lg" \| "icon" \| "icon-xs" \| "icon-sm" \| "icon-lg"` | `"default"` |

See the [React Aria](https://react-aria.adobe.com/Button#api) documentation for more information.
