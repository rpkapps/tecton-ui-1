## Portal container

`Drawer` portals into the `portalContainer` of the nearest [`TectonProvider`](/docs/tecton/provider), like every other Tecton overlay. Without one it portals into `document.body`.

That matters for an application mounted into a page that has its own copy of Tecton. Wrap it in [`ThemeRoot`](/docs/tecton/theme-root) and the drawer lands in that root's body-level overlay container, which carries the same theme class, scope class and token overrides as the application itself — so the drawer is styled by the copy of Tecton that rendered it. See [Micro-frontends](/docs/micro-frontends).
