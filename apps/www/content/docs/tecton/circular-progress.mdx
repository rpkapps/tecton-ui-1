## Usage

```tsx
import { CircularProgress } from "@tecton/react/tecton/circular-progress"
```

```tsx
<CircularProgress aria-label="Resampling" value={64} showValue />
```

<Callout>
  The shadcn [Progress](/docs/components/progress) is a linear bar and [Spinner](/docs/components/spinner) is an icon. Tecton's circular progress with a value label is a separate component.
</Callout>

## Sizes

Use the `size` prop from 16 px (`xs`) to 96 px (`xl`). Stroke width and label size scale with it.

<ComponentPreview name="circular-progress-sizes" />

## Colors

Use the `color` prop for the ring colour. `default` paints the ring with the shared `progress` token, the same fill as the linear [Progress](/docs/components/progress); the track is that colour at 38 %.

<ComponentPreview name="circular-progress-colors" />

## Value label

Set `showValue` to render the formatted value in the centre, or pass children for custom content. `minValue`, `maxValue` and `formatOptions` come from React Aria.

<ComponentPreview name="circular-progress-value" />

## Indeterminate

Set `isIndeterminate` for a spinning ring while the amount of work is unknown. With reduced motion requested the ring keeps turning slowly rather than stopping: a still arc would read as a stuck value.

## Usage guidelines

### Use it when

- The progress belongs in a compact space: a card corner, a table cell, a tile, a KPI.
- The number matters as much as the arc: `showValue`, or children such as `7/12`.
- A ring, not an icon, is the right weight for an indeterminate wait inside a panel or a dialog.

### Not for

- a full-width determinate bar in the flow of a panel: use [Progress](/docs/components/progress)
- a small busy glyph inside a button or an input: use [Spinner](/docs/components/spinner)
- a segmented readout of risk, complexity or confidence: use [Meter](/docs/tecton/meter)

### Do

<DoList>

<Do>

Always pass `aria-label`; there is no visible label slot.

</Do>

<Do>

Size with `size="xs" | "sm" | "md" | "lg" | "xl"` (16 / 24 / 40 / 64 / 96 px): one prop drives the diameter, the stroke width and the centre type together.

</Do>

<Do>

Colour with `color="default" | "foreground" | "success" | "warning" | "error" | "info"`; `default` is the shared `progress` fill.

</Do>

<Do>

Give the scale with `minValue` and `maxValue`, shape the text with `formatOptions`, or pass children for custom centre content.

</Do>

<Do>

Use `isIndeterminate`, not `value={0}`, while the total is unknown.

</Do>

</DoList>

### Don't

<Dont severity="CRITICAL" title="A ring with no accessible name">

<Wrong>

```tsx
<CircularProgress value={64} showValue />
```

</Wrong>

<Correct>

```tsx
<CircularProgress aria-label="Resampling" value={64} showValue />
```

</Correct>

The `svg` is `aria-hidden` and `role="progressbar"` takes no name from its contents, so without `aria-label` the ring is announced as an unnamed progress bar.

</Dont>

<Dont severity="HIGH" title="Sizing or colouring the ring with className">

<Wrong>

```tsx
<CircularProgress
  aria-label="Export"
  value={40}
  className="size-20 text-blue-600"
/>
```

</Wrong>

<Correct>

```tsx
<CircularProgress aria-label="Export" value={40} size="lg" color="default" />
```

</Correct>

`size` also sets the `--stroke` width and the centre label's type scale, so overriding only the diameter leaves a hairline ring, and `blue-600` is not a Tecton step — `cn` drops `text-progress` for a class that emits nothing and the stroke falls back to the inherited text colour.

</Dont>

<Dont severity="MEDIUM" title="showValue on an indeterminate ring">

<Wrong>

```tsx
<CircularProgress size="sm" isIndeterminate showValue aria-label="Loading well logs" />
```

</Wrong>

<Correct>

```tsx
<div className="flex items-center gap-3 text-sm text-muted-foreground">
  <CircularProgress size="sm" isIndeterminate aria-label="Loading well logs" />
  Loading well logs…
</div>
```

</Correct>

The centre label renders only when `showValue && !isIndeterminate`, so the prop is ignored and the ring spins with an empty middle where the caption was expected.

</Dont>

{/* guidelines:end */}

## API Reference

### CircularProgress

React Aria [`ProgressBar`](https://react-aria.adobe.com/ProgressBar); accepts all its props (`value`, `minValue`, `maxValue`, `isIndeterminate`, `formatOptions`, `valueLabel`…).

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `size` | `"xs" \| "sm" \| "md" \| "lg" \| "xl"` | "md" | Diameter 16 / 24 / 40 / 64 / 96 px. |
| `color` | `"default" \| "foreground" \| "success" \| "warning" \| "error" \| "info"` | "default" | Ring colour; `default` is the `progress` token. |
| `showValue` | `boolean` | false | Show the formatted value in the centre. |
| `children` | `ReactNode` | - | Custom centre content (overrides `showValue`). |
| `aria-label` | `string` | - | Accessible name (required without a visible label). |
