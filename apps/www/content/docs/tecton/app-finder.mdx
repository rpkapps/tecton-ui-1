## Usage

```tsx
import {
  AppFinder,
  AppFinderGroup,
  AppFinderInput,
  AppFinderItem,
  AppFinderList,
  AppFinderMenu,
  AppFinderTrigger,
} from "@tecton/react/tecton/app-finder"
```

```tsx
<AppFinder>
  <AppFinderTrigger name="Well Planning" tone="green">
    DWP
  </AppFinderTrigger>
  <AppFinderMenu>
    <AppFinderInput />
    <AppFinderList onSelect={(value) => navigateTo(value)}>
      <AppFinderGroup heading="Recent" hideWhileSearching>
        <AppFinderItem value="recent-dsg" icon="DSG" tone="blue" name="Discovery" />
      </AppFinderGroup>
      <AppFinderGroup heading="Subsurface">
        <AppFinderItem value="dsg" icon="DSG" tone="blue" name="Discovery" description="Regional geology" keywords={["DSG"]} />
      </AppFinderGroup>
      <AppFinderGroup heading="Wells">
        <AppFinderItem value="dwp" icon="DWP" tone="green" name="Well Planning" keywords={["DWP"]} current />
      </AppFinderGroup>
    </AppFinderList>
  </AppFinderMenu>
</AppFinder>
```

The app finder replaces the static brand in [`AppShellBrand`](/docs/tecton/app-shell). Typing filters every group at once on the item's `name` and `keywords` and highlights the match; the list scrolls past 24 rem, so a catalogue of a few hundred applications stays usable. The popover closes after `onSelect`.

## Large catalogues

- Keep every `value` unique: an app listed under both "Recent" and its category needs two values (`recent-dwp` and `dwp`).
- Mark the "Recent" or "Favourites" group `hideWhileSearching` so a query lists each app once.
- Put the short code and the category in `keywords` so a search for either finds the app.
- Give each category one `tone` (`neutral`, `blue`, `azure`, `green`, `lime`, `yellow`, `saffron`, `red`, `pink`, `orchid`, `mauve`, `violet`, `lilac`) so a family can be found by colour.

## Usage guidelines

### Use it when

- The shell header switches between independently deployed applications.
- The catalogue is large enough that a flat menu stops working: categories, search, short codes.
- The current application has to stay visible in the header as a tinted code tile.

### Not for

- a short list of actions opened from a header button: use [DropdownMenu](/docs/components/dropdown-menu)
- a palette of commands and records inside one application: use [Command](/docs/components/command)
- the global action cluster at the end of the shell header: use [AppShellActions](/docs/tecton/app-shell)

### Do

<DoList>

<Do>

Compose `AppFinder` > (`AppFinderTrigger`, `AppFinderMenu` > `AppFinderInput` + `AppFinderList` > `AppFinderGroup` > `AppFinderItem`).

</Do>

<Do>

Describe the current app on the trigger: the short code as children, `name` for the label beside the tile, the category's `tone`.

</Do>

<Do>

Navigate from `onSelect` on `AppFinderList`; it receives the item's `value` and closes the popover afterwards. Control the popover with `open` / `onOpenChange` on `AppFinder` when you need to.

</Do>

<Do>

Give every item a unique `value` across groups, `keywords` for its short code and category, and `current` on the mounted one; the filter matches `name` and `keywords`, never `value`.

</Do>

<Do>

Reuse `AppFinderIcon` wherever else the tile is needed — a launcher grid, a command palette row.

</Do>

</DoList>

### Don't

<Dont severity="CRITICAL" title="Hand-tinting the app tile with className">

<Wrong>

```tsx
<AppFinderItem value="dwp" icon="DWP" name="Well Planning" className="bg-emerald-100 text-emerald-800" />
```

</Wrong>

<Correct>

```tsx
<AppFinderItem value="dwp" icon="DWP" tone="green" name="Well Planning" />
```

</Correct>

`className` lands on the row and never on the tile, and `emerald` is not a Tecton palette family, so both classes emit no CSS under the reset palette — `tone` is the `cva` axis that paints the tile `bg-green-120 text-green-830`.

</Dont>

<Dont severity="HIGH" title="A search field of your own above the list">

<Wrong>

```tsx
<AppFinderMenu>
  <Input value={query} onChange={(event) => setQuery(event.target.value)} />
  <AppFinderList onSelect={switchTo}>{appsMatching(query)}</AppFinderList>
</AppFinderMenu>
```

</Wrong>

<Correct>

```tsx
<AppFinderMenu>
  <AppFinderInput />
  <AppFinderList onSelect={switchTo}>{everyApp}</AppFinderList>
</AppFinderMenu>
```

</Correct>

`AppFinderMenu` mounts a `Command` that owns the query, and `AppFinderInput` is the `CommandInput` bound to it: a separate `Input` leaves that value empty, so the filter over each item's `name` and `keywords` never runs, the match is never highlighted, and the arrow keys no longer move from the field into the list.

</Dont>

<Dont severity="MEDIUM" title="A Recent group left visible while searching">

<Wrong>

```tsx
<AppFinderGroup heading="Recent">
  <AppFinderItem value="recent-dwp" icon="DWP" tone="green" name="Well Planning" />
</AppFinderGroup>
```

</Wrong>

<Correct>

```tsx
<AppFinderGroup heading="Recent" hideWhileSearching>
  <AppFinderItem value="recent-dwp" icon="DWP" tone="green" name="Well Planning" />
</AppFinderGroup>
```

</Correct>

The filter runs across every group at once, so without `hideWhileSearching` a query lists the same application twice — once from "Recent", once from its category — under two different values, and `onSelect` reports whichever row the user happened to press.

</Dont>

{/* guidelines:end */}

## API Reference

### AppFinder

The popover root; renders no element.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `open` | `boolean` | - | Controlled open state. |
| `defaultOpen` | `boolean` | `false` | Initial open state. |
| `onOpenChange` | `(open: boolean) => void` | - | Called when the menu opens or closes. |

### AppFinderTrigger

Ghost `Button` showing the current app's tile, its name from `sm` up, and a chevron. Accepts `Button` props.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `children` | `ReactNode` | - | Short code of the current app, shown in the tile. |
| `name` | `string` | - | Name of the current app; also gives the default `aria-label` `"Switch application, current: {name}"`. |
| `tone` | `AppFinderTone` | `"neutral"` | Colour of the tile. |

### AppFinderMenu

The popover, 26 rem wide. The query resets every time it opens.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `aria-label` | `string` | `"Applications"` | Accessible name of the palette. |
| `side` | `"top" \| "bottom" \| "left" \| "right" \| "inline-start" \| "inline-end"` | `"bottom"` | Side of the trigger. |
| `align` | `"start" \| "center" \| "end"` | `"start"` | Alignment along that side. |
| `sideOffset` / `alignOffset` | `number` | `6` / `0` | Offsets in px. |
| `container` | `HTMLElement \| null` | overlay container | Element the popover is portalled into. |

### AppFinderInput

The search field; focused when the menu opens. Arrow keys move through the results and Enter chooses.

| Prop | Type | Default |
| --- | --- | --- |
| `placeholder` | `string` | `"Search applications…"` |

### AppFinderList

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `onSelect` | `(value: string) => void` | - | Called with the chosen app's `value`; the menu then closes. |
| `emptyMessage` | `ReactNode` | `"No applications match"` | Shown when nothing matches. |
| `emptyHint` | `ReactNode` | `"Try the app's short code or its category"` | Second line of the empty state; `null` drops it. |

### AppFinderGroup

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `heading` | `ReactNode` | - | Category label. |
| `hideWhileSearching` | `boolean` | `false` | Leave the group out while a query is typed. |

### AppFinderItem

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `value` | `string` | - | Identity passed to `onSelect`; not searched. |
| `name` | `string` | - | Display name; searched (case-insensitive substring). |
| `description` | `ReactNode` | - | Secondary line. |
| `icon` | `ReactNode` | - | Glyph or short code in the tile. |
| `tone` | `AppFinderTone` | `"neutral"` | Colour of the tile. |
| `keywords` | `string[]` | - | Extra words the search matches. |
| `current` | `boolean` | `false` | Marks the app being shown with a "Current" check. |

### AppFinderIcon

The tile on its own (a `span` with `tone` and `size`: `"sm"` or `"default"`), e.g. for a launcher grid.
