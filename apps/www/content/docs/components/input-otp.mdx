## About

Input OTP is built on top of [input-otp](https://github.com/guilhermerodz/input-otp) by [@guilherme_rodz](https://twitter.com/guilherme_rodz).

## Usage

```tsx showLineNumbers
import {
  InputOTP,
  InputOTPGroup,
  InputOTPSeparator,
  InputOTPSlot,
} from "@tecton/react/components/input-otp"
```

```tsx showLineNumbers
<InputOTP maxLength={6}>
  <InputOTPGroup>
    <InputOTPSlot index={0} />
    <InputOTPSlot index={1} />
    <InputOTPSlot index={2} />
  </InputOTPGroup>
  <InputOTPSeparator />
  <InputOTPGroup>
    <InputOTPSlot index={3} />
    <InputOTPSlot index={4} />
    <InputOTPSlot index={5} />
  </InputOTPGroup>
</InputOTP>
```

## Composition

Use the following composition to build an `InputOTP`:

```text
InputOTP
├── InputOTPGroup
│   ├── InputOTPSlot
│   ├── InputOTPSlot
│   └── InputOTPSlot
├── InputOTPSeparator
├── InputOTPGroup
│   ├── InputOTPSlot
│   ├── InputOTPSlot
│   └── InputOTPSlot
├── InputOTPSeparator
└── InputOTPGroup
    ├── InputOTPSlot
    └── InputOTPSlot
```

## Pattern

Use the `pattern` prop to define a custom pattern for the OTP input.

```tsx showLineNumbers {1,5}
import { REGEXP_ONLY_DIGITS_AND_CHARS } from "input-otp"

;<InputOTP maxLength={6} pattern={REGEXP_ONLY_DIGITS_AND_CHARS}>
  ...
</InputOTP>
```

## Usage guidelines

### Use it when

- A one-time code from email, SMS or an authenticator app.
- A short fixed-length PIN the user reads from somewhere and types once.
- The value has a known length and every character deserves its own box.

### Not for

- a password, a token or any other free-form value: use [Input](/docs/components/input)
- a field with an icon or a button attached: use [InputGroup](/docs/components/input-group)
- the label, description and error message around the code: use [Field](/docs/components/field)

### Do

<DoList>

<Do>

Set `maxLength` to the number of `InputOTPSlot` children, and give each slot its absolute `index` across every group.

</Do>

<Do>

Control it with `value` and `onChange(value: string)`, or leave it uncontrolled with `defaultValue`.

</Do>

<Do>

Restrict the alphabet with `pattern={REGEXP_ONLY_DIGITS}` or `REGEXP_ONLY_DIGITS_AND_CHARS` from `input-otp`.

</Do>

<Do>

Split long codes with `InputOTPGroup` and `InputOTPSeparator`, and mark errors with `aria-invalid` on each `InputOTPSlot`.

</Do>

<Do>

Wrap it in a `Field` with a `FieldLabel htmlFor` pointing at the `InputOTP` id, and disable with `disabled`.

</Do>

</DoList>

### Don't

<Dont severity="HIGH" title="Restarting the slot index in each group">

<Wrong>

```tsx
<InputOTP maxLength={4}>
  <InputOTPGroup>
    <InputOTPSlot index={0} />
    <InputOTPSlot index={1} />
  </InputOTPGroup>
  <InputOTPSeparator />
  <InputOTPGroup>
    <InputOTPSlot index={0} />
    <InputOTPSlot index={1} />
  </InputOTPGroup>
</InputOTP>
```

</Wrong>

<Correct>

```tsx
<InputOTP maxLength={4}>
  <InputOTPGroup>
    <InputOTPSlot index={0} />
    <InputOTPSlot index={1} />
  </InputOTPGroup>
  <InputOTPSeparator />
  <InputOTPGroup>
    <InputOTPSlot index={2} />
    <InputOTPSlot index={3} />
  </InputOTPGroup>
</InputOTP>
```

</Correct>

`index` addresses the shared `OTPInputContext` slot array, so repeated indices echo the first characters twice and the rest of the code is never displayed.

</Dont>

<Dont severity="MEDIUM" title="Marking the group invalid instead of the slots">

<Wrong>

```tsx
<InputOTPGroup aria-invalid>
  <InputOTPSlot index={0} />
  <InputOTPSlot index={1} />
</InputOTPGroup>
```

</Wrong>

<Correct>

```tsx
<InputOTPGroup>
  <InputOTPSlot index={0} aria-invalid />
  <InputOTPSlot index={1} aria-invalid />
</InputOTPGroup>
```

</Correct>

`InputOTPGroup` paints its error state with `has-aria-invalid:`, which looks for a descendant, so `aria-invalid` on the group itself styles nothing.

</Dont>
