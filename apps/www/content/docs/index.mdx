**Tecton UI** is the React implementation of the Tecton design system. Add one package,
import a component, and you get the Tecton look, the Tecton behaviour and both themes —
with no design decisions left for your application to make.

## What you get

- **`@tecton/react`** — over 60 interface components (`@tecton/react/components/*`), the
  Tecton-specific components (`@tecton/react/tecton/*`), the icon set
  (`@tecton/react/icons`), ready-made blocks and the theme stylesheet.
- **Accessible by default** — keyboard behaviour, focus management, selection and ARIA
  semantics are part of every component, not something you add later.
- **The Tecton design tokens** — colours, radii, spacing and typography come straight
  from the design-system export, in dark and light. See [Theming](/docs/theming).
- **Guardrails** — `@tecton/eslint-config` catches the changes that silently break the
  look, and tells you the variant to use instead. See [Linting](/docs/linting).

## Principles

<Callout title="The component owns its appearance">
  Colour, shape, size, spacing and type belong to the component and its variants;
  placement belongs to your application. If a design needs something no variant offers,
  that is a change to the design system, not a `className` at the call site — which is
  why the same screen looks the same in every Tecton application.
</Callout>

- **Dark first.** Tecton applications run dark by default; the light theme is equally
  complete and comes from the same token export.
- **One import path.** Nothing is copied into your repository and nothing is per-project
  configuration, so every application upgrades with the package.
- **Composable.** Components are small building blocks styled with Tailwind, designed to
  be assembled rather than configured.
