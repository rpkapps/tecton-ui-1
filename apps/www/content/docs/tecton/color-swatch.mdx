## Usage

```tsx
import { ColorSwatch } from "@tecton/react/tecton/color-swatch"
```

```tsx
<ColorSwatch color="#f59e0b" label="Sandstone" value="#f59e0b" />
```

## Sizes

Use the `size` prop, from 12 px (`xs`) to 48 px (`xl`).

## Shapes

Use the `shape` prop for square, rounded or circular swatches.

## Labels

Pass `label` and/or `value` to render text next to the swatch; the value is set in the mono font.

The swatch is a `role="img"` whose accessible name is your `aria-label` (or a string `label`) followed by an English name of the colour, such as "Sandstone, vibrant orange". `colorName` replaces the generated name.

<ComponentPreview name="color-swatch-labels" />

## Editable

Pass `onChange` to make the swatch a button that opens a picker: a radio group of preset colours (the Tecton accent fills by default; override with `presets`), the platform colour picker and a hex field. `onChange` receives the new colour as `#RRGGBB`.

- The presets are radios labelled "Presets": Tab enters the group on the checked preset, and the arrow keys move **and select**, so each arrow press calls `onChange`.
- The hex field commits on Enter or blur. It accepts a hex with or without `#` and any other CSS colour; input that is not a colour reverts to the current value. Alpha is dropped.

## Usage guidelines

### Use it when

- The colour *is* the data: a horizon colour, a facies legend, a theme token, a series fill.
- The colour needs its name or its value beside it: `label` and `value`.
- The user has to change it: `onChange` turns the swatch into a button with a preset and hex picker.

### Not for

- a label that names a status or a category in words: use [Badge](/docs/components/badge)
- the colour key for the series of a chart: use [ChartLegendContent](/docs/components/chart)
- a count or a dot pinned to the corner of an icon or an avatar: use [CountBadge](/docs/tecton/count-badge)

### Do

<DoList>

<Do>

Pass any CSS colour to `color` — a hex, `rgb()`, `hsl()`, `oklch()`, a keyword or `var(--tecton-color-accent-lime-fill)`; a translucent colour shows over a checkerboard.

</Do>

<Do>

Size with `size="xs" | "sm" | "md" | "lg" | "xl"` (12 to 48 px) and pick the corner with `shape="square" | "rounded" | "circle"`.

</Do>

<Do>

Name what the colour stands for with `aria-label` (or a string `label`); the swatch appends the colour's English name itself ("Sandstone, vibrant orange"), and `colorName` replaces that name.

</Do>

<Do>

Make it editable with `onChange`, which receives `#RRGGBB`, and replace the Tecton accent presets with `presets` when the palette is domain-specific; the presets are a radio group, so an arrow key selects as it moves.

</Do>

</DoList>

### Don't

<Dont severity="HIGH" title="A coloured div in place of the swatch">

<Wrong>

```tsx
<div
  className="size-6 rounded-md"
  style={{ background: horizon.color }}
/>
```

</Wrong>

<Correct>

```tsx
<ColorSwatch
  color={horizon.color}
  size="md"
  aria-label={`${horizon.name} colour`}
/>
```

</Correct>

The swatch is `role="img"` with an accessible name and carries `border border-border-subtle shadow-xs`, which is what keeps a white, pale or transparent colour visible against the surface; a bare div is silent to assistive technology and its inline `style` is what `no-inline-styles` reports.

</Dont>

<Dont severity="HIGH" title="Opening the picker with a click handler">

<Wrong>

```tsx
<ColorSwatch color={color} onClick={() => setPickerOpen(true)} />
```

</Wrong>

<Correct>

```tsx
<ColorSwatch color={color} onChange={setColor} aria-label="Series colour" />
```

</Correct>

Without `onChange` the swatch is a non-focusable `role="img"` `span`, so an `onClick` on it is out of reach of the keyboard and of assistive technology; `onChange` wraps it in the `color-swatch-trigger` button that opens the preset radio group and the hex field.

</Dont>

<Dont severity="MEDIUM" title="Label and value written as sibling spans">

<Wrong>

```tsx
<div className="flex items-center gap-2">
  <ColorSwatch color="#f59e0b" />
  <span className="text-sm">Sandstone</span>
  <span className="font-mono text-xs text-zinc-500">#f59e0b</span>
</div>
```

</Wrong>

<Correct>

```tsx
<ColorSwatch color="#f59e0b" label="Sandstone" value="#f59e0b" />
```

</Correct>

With `label` and `value` the component renders the `color-swatch-item` row itself — name over value, the value in the mono face and `muted-foreground`, `className` moved from the swatch to the row — while `text-zinc-500` is stock Tailwind that emits no CSS at all.

</Dont>

{/* guidelines:end */}

## API Reference

### ColorSwatch

Other props (`id`, `className`, `style`, `data-*`, `aria-*`, event handlers, `ref`) go to the swatch `span`.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `color` | `string` | `"transparent"` | Any CSS colour: hex, `rgb()`, `hsl()`, `oklch()`, a keyword or `var(--token)`. |
| `colorName` | `string` | generated | Replaces the English colour name in the accessible name. |
| `size` | `"xs" \| "sm" \| "md" \| "lg" \| "xl"` | "md" | Swatch size. |
| `shape` | `"square" \| "rounded" \| "circle"` | "rounded" | Corner radius. |
| `label` | `ReactNode` | - | Text next to the swatch. |
| `value` | `ReactNode` | - | Secondary mono text (e.g. the hex value). |
| `onChange` | `(color: string) => void` | - | Makes the swatch editable; called with the picked colour as `#RRGGBB`. |
| `presets` | `string[]` | Tecton accents | Preset colours shown by the editable picker; any CSS colour or `var(--token)`. A value that does not resolve to a colour is left out. |
| `aria-label` | `string` | - | What the colour stands for, placed before the colour name; names the button when editable (default "Edit colour"). |
