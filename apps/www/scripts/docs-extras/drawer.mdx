## Portal container

Like every Tecton overlay, `Drawer` portals into the `portalContainer` of the nearest [`TectonProvider`](/docs/tecton/provider), else into `document.body`; `container` on `DrawerContent` overrides both. Inside a [`ThemeRoot`](/docs/tecton/theme-root) that is the root's overlay container, which carries the application's theme and scope classes, so a mounted application's drawer keeps its styles. See [Micro-frontends](/docs/micro-frontends).
