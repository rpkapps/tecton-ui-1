## Usage

```tsx
import { Meter } from "@tecton/react/tecton/meter"
```

```tsx
<Meter label="Drilling complexity" value={60} valueLabel="Medium" color="auto" />
```

A meter shows a level; for task progress use [Progress](/docs/components/progress). `showValue` prints the formatted value at the end of the label row, and `valueLabel` replaces it with your own text ("Medium"). A string `valueLabel` is also what screen readers announce, instead of a percentage.

## Segments

`segments` sets the number of blocks; `segments={1}` is a continuous bar. A partly filled segment shows the exact value.

## Auto color

`color="auto"` picks `success` below 34 %, `warning` below 67 % and `error` above.

## Usage guidelines

### Use it when

- A score or a level is being read, not a task being completed: geological risk, drilling complexity, confidence, data quality.
- The value sits on a fixed scale with named bands (low / medium / high).
- The readout belongs on a card, in a table cell or in a panel row, with a label and a word for the value.

### Not for

- the completion of a task that will finish: use [Progress](/docs/components/progress)
- an indeterminate wait: use [Spinner](/docs/components/spinner)
- a one-word risk label in a row or a header: use [Badge](/docs/components/badge)

### Do

<DoList>

<Do>

Name it: `label` renders the visible label that names the meter; use `aria-label` when the name is already beside it.

</Do>

<Do>

State the scale with `min` and `max` whenever it is not 0–100; the segments fill from the percentage.

</Do>

<Do>

Choose `segments` (5 by default, `1` for a continuous bar) and `size="sm" | "md" | "lg"`.

</Do>

<Do>

Let `color="auto"` pick success / warning / error from the value, or fix it with `color`; `color="custom"` reads `--meter-fill`.

</Do>

<Do>

Show the band with `valueLabel="Medium"` and the raw number with `showValue`.

</Do>

</DoList>

### Don't

<Dont severity="CRITICAL" title="A meter with no accessible name">

<Wrong>

```tsx
<Meter value={60} valueLabel="Medium" className="max-w-xs" />
```

</Wrong>

<Correct>

```tsx
<Meter label="Drilling complexity" value={60} valueLabel="Medium" className="max-w-xs" />
```

</Correct>

The segments are plain `span`s and `role="meter"` takes no name from them, so without `label` or `aria-label` the gauge announces a number with nothing to attach it to.

</Dont>

<Dont severity="HIGH" title="A raw score on the default 0–100 scale">

<Wrong>

```tsx
<Meter label="Confidence" value={4} showValue />
```

</Wrong>

<Correct>

```tsx
<Meter label="Confidence" value={4} max={5} showValue />
```

</Correct>

`max` defaults to `100`, so a 4-out-of-5 score fills 4 % of the track and is announced as 4 %.

</Dont>

<Dont severity="MEDIUM" title="Re-deriving the colour bands by hand">

<Wrong>

```tsx
<Meter
  label="Geological risk"
  value={risk}
  color={risk >= 67 ? "error" : risk >= 34 ? "warning" : "success"}
/>
```

</Wrong>

<Correct>

```tsx
<Meter label="Geological risk" value={risk} color="auto" />
```

</Correct>

`color="auto"` already applies the 34 / 67 thresholds to the percentage, so the hand-written ternary duplicates a design-system decision and disagrees with it as soon as `min` or `max` is not 0–100.

</Dont>

<Dont severity="MEDIUM" title="Colouring the segments with className">

<Wrong>

```tsx
<Meter label="Data quality" value={80} className="bg-green-600" />
```

</Wrong>

<Correct>

```tsx
<Meter label="Data quality" value={80} color="success" />
```

</Correct>

`className` lands on the meter's outer flex column, not on the segment fills, which take their class from `color` — and `green-600` is not a Tecton step, so nothing is emitted for it either.

</Dont>

{/* guidelines:end */}

## API Reference

### Meter

A `div` with `role="meter"`; accepts `div` props.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `value` | `number` | - | Current value. |
| `min` / `max` | `number` | `0` / `100` | Scale of `value`. |
| `format` | `Intl.NumberFormatOptions` | percent | Format of the shown and announced value. |
| `locale` | `Intl.LocalesArgument` | runtime locale | Locale of the formatted value. |
| `label` | `ReactNode` | - | Visible label; use `aria-label` otherwise. |
| `segments` | `number` | `5` | Number of blocks. |
| `color` | `"default" \| "success" \| "warning" \| "error" \| "info" \| "auto" \| "custom"` | `"default"` | Fill colour. |
| `size` | `"sm" \| "md" \| "lg"` | `"md"` | Track height 4 / 6 / 10 px. |
| `showValue` | `boolean` | `false` | Show the formatted value. |
| `valueLabel` | `ReactNode` | - | Custom value text; a string or number is also announced. |
