## Usage

```tsx lineNumbers
import {
  Sheet,
  SheetClose,
  SheetDescription,
  SheetFooter,
  SheetHeader,
  SheetTitle,
  SheetTrigger,
} from "@tecton/react/components/sheet"
```

```tsx lineNumbers
<SheetTrigger>
  <Button>Open</Button>
  <Sheet>
    <SheetHeader>
      <SheetTitle>Are you absolutely sure?</SheetTitle>
      <SheetDescription>This action cannot be undone.</SheetDescription>
    </SheetHeader>
  </Sheet>
</SheetTrigger>
```

## Composition

Use the following composition to build a `Sheet`:

```text
SheetTrigger
├── Button
└── Sheet
    ├── SheetHeader
    │   ├── SheetTitle
    │   └── SheetDescription
    └── SheetFooter
```

## Side

Use the `side` prop on `SheetContent` to set the edge of the screen where the sheet appears. Values are `top`, `right`, `bottom`, or `left`.

## Usage guidelines

### Use it when

- Details, filters or settings that belong to what is on screen: the page stays behind the overlay.
- The content is taller than it is wide — a form, a property list, a history.
- The user should be able to leave by clicking the page behind it.

### Not for

- a decision that must be finished before anything else: use [Dialog](/docs/components/dialog)
- a bottom sheet the user drags with a thumb on touch: use [Drawer](/docs/components/drawer)
- a panel that belongs to the page instead of floating over it: use [Panel](/docs/tecton/panel)
- content anchored to the control that opened it: use [Popover](/docs/components/popover)

### Do

<DoList>

<Do>

Compose `Sheet` (the root) > `SheetTrigger render={<Button />}` + `SheetContent`, exactly as for `Dialog`; state is `open` / `onOpenChange` on `Sheet`.

</Do>

<Do>

Pick the edge with `side="right" | "left" | "top" | "bottom"` on `SheetContent`.

</Do>

<Do>

Let `SheetHeader` and `SheetFooter` carry their own `p-4`; the sheet body is yours, so give it `px-4` and `flex-1`.

</Do>

<Do>

Drop the corner control with `showCloseButton={false}` on `SheetContent` and close from the footer with `SheetClose render={<Button variant="outline" />}`.

</Do>

<Do>

Set width with `className` on `SheetContent` (`sm:max-w-lg`) only; it owns the surface, the edge and the animation.

</Do>

</DoList>

### Don't

<Dont severity="HIGH" title="Positioning the sheet with className">

<Wrong>

```tsx
<SheetContent className="fixed top-0 left-0 h-full w-96 bg-white p-6">
  <SheetTitle>Well properties</SheetTitle>
</SheetContent>
```

</Wrong>

<Correct>

```tsx
<SheetContent side="left" className="sm:max-w-md">
  <SheetHeader><SheetTitle>Well properties</SheetTitle></SheetHeader>
</SheetContent>
```

</Correct>

`SheetContent` sets its edge, size and enter/exit transforms from `data-side`, so hand-placed `fixed`/`inset` classes fight the variant and the animation slides the panel from the wrong edge.

</Dont>

<Dont severity="HIGH" title="Body content with no padding of its own">

<Wrong>

```tsx
<SheetContent>
  <SheetHeader><SheetTitle>Filters</SheetTitle></SheetHeader>
  <FieldGroup>
    <Input aria-label="Field" />
  </FieldGroup>
</SheetContent>
```

</Wrong>

<Correct>

```tsx
<SheetContent>
  <SheetHeader><SheetTitle>Filters</SheetTitle></SheetHeader>
  <FieldGroup className="flex-1 px-4">
    <Input aria-label="Field" />
  </FieldGroup>
</SheetContent>
```

</Correct>

The padding lives on `SheetHeader` and `SheetFooter`, not on the sheet, so anything in between runs edge to edge against the panel border.

</Dont>

<Dont severity="MEDIUM" title="The side on the root">

<Wrong>

```tsx
<Sheet side="left">
  <SheetTrigger render={<Button variant="outline" />}>Filters</SheetTrigger>
  <SheetContent><SheetTitle>Filters</SheetTitle></SheetContent>
</Sheet>
```

</Wrong>

<Correct>

```tsx
<Sheet>
  <SheetTrigger render={<Button variant="outline" />}>Filters</SheetTrigger>
  <SheetContent side="left"><SheetTitle>Filters</SheetTitle></SheetContent>
</Sheet>
```

</Correct>

`Sheet` is the state root and renders no element, so `side` there is ignored and the panel opens from the default right edge.

</Dont>

{/* guidelines:end */}
