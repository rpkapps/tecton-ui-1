## About

The `<Command />` component uses the [`cmdk`](https://github.com/dip/cmdk) component by [Dip](https://www.dip.org/).

## Usage

```tsx lineNumbers
import {
  Command,
  CommandDialog,
  CommandEmpty,
  CommandGroup,
  CommandInput,
  CommandItem,
  CommandList,
  CommandSeparator,
  CommandShortcut,
} from "@tecton/react/components/command"
```

```tsx lineNumbers
<Command className="max-w-sm rounded-lg border">
  <CommandInput placeholder="Type a command or search..." />
  <CommandList>
    <CommandEmpty>No results found.</CommandEmpty>
    <CommandGroup heading="Suggestions">
      <CommandItem>Calendar</CommandItem>
      <CommandItem>Search Emoji</CommandItem>
      <CommandItem>Calculator</CommandItem>
    </CommandGroup>
    <CommandSeparator />
    <CommandGroup heading="Settings">
      <CommandItem>Profile</CommandItem>
      <CommandItem>Billing</CommandItem>
      <CommandItem>Settings</CommandItem>
    </CommandGroup>
  </CommandList>
</Command>
```

## Composition

Use the following composition to build a `Command`:

```text
Command
├── CommandInput
└── CommandList
    ├── CommandEmpty
    ├── CommandGroup
    │   ├── CommandItem
    │   └── CommandItem
    ├── CommandSeparator
    └── CommandGroup
        ├── CommandItem
        └── CommandItem
```

## Usage guidelines

### Use it when

- The user should reach commands and records by typing, from anywhere in the application.
- The surface is a palette, usually inside `CommandDialog`, rather than a field in a form.
- The list mixes groups of actions and wants keyboard-shortcut hints beside them.

### Not for

- picking a value for a form field: use [Combobox](/docs/components/combobox)
- a menu of actions opened from a button: use [DropdownMenu](/docs/components/dropdown-menu)
- a menu opened by right click: use [ContextMenu](/docs/components/context-menu)

### Do

<DoList>

<Do>

Run the action from `onSelect` on `CommandItem`; it fires on click and on Enter.

</Do>

<Do>

Put `CommandEmpty` inside `CommandList`: it shows only when the filter matches nothing.

</Do>

<Do>

Give an item whose children are JSX a `value` (and `keywords` for synonyms), so the filter matches the words, not the markup.

</Do>

<Do>

Group with `CommandGroup heading="…"`, divide with `CommandSeparator`, hint keys with `CommandShortcut` — a label only, since Tecton binds no keys.

</Do>

<Do>

Open the palette with `CommandDialog` and its `open` / `onOpenChange` props, wrapping a `Command`.

</Do>

<Do>

Keep the `Command` palette short: a few groups, with record results capped (the first ten wells) rather than every match.

</Do>

<Do>

When a filter narrows a table or list, show the matching count beside it ("42 of 318 wells").

</Do>

</DoList>

### Don't

<Dont severity="CRITICAL" title="The onAction prop instead of onSelect">

<Wrong>

```tsx
<CommandItem onAction={() => router.navigate({ to: "/wells" })}>Go to wells</CommandItem>
```

</Wrong>

<Correct>

```tsx
<CommandItem onSelect={() => router.navigate({ to: "/wells" })}>Go to wells</CommandItem>
```

</Correct>

`CommandItem` is a cmdk item whose activation handler is `onSelect`; `onAction` is not in its props, so pressing Enter or clicking the row does nothing at all.

</Dont>

<Dont severity="HIGH" title="A textValue instead of value and keywords">

<Wrong>

```tsx
<CommandItem textValue="Billing" onSelect={openBilling}>
  <CreditCardIcon />
  <span>Billing</span>
</CommandItem>
```

</Wrong>

<Correct>

```tsx
<CommandItem value="billing" keywords={["invoice", "payment"]} onSelect={openBilling}>
  <CreditCardIcon />
  <span>Billing</span>
</CommandItem>
```

</Correct>

The filter matches an item's `value` and `keywords`; `textValue` is not a prop, so the item is matched on whatever text cmdk reads from its markup and a search for "invoice" finds nothing.

</Dont>

<Dont severity="MEDIUM" title="An empty search that renders nothing">

<Wrong>

```tsx
<Command>
  <CommandInput placeholder="Type a command or search…" />
  <CommandList>{items}</CommandList>
</Command>
```

</Wrong>

<Correct>

```tsx
<Command>
  <CommandInput placeholder="Type a command or search…" />
  <CommandList>
    <CommandEmpty>No results found.</CommandEmpty>
    {items}
  </CommandList>
</Command>
```

</Correct>

With no `CommandEmpty` a search that matches nothing leaves a blank panel under the input, which reads as the palette having broken.

</Dont>

{/* guidelines:end */}
