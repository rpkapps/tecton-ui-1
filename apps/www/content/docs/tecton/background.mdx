## Usage

```tsx
import { ContourBackground } from "@tecton/react/tecton/background"
```

```tsx
<section className="relative isolate overflow-hidden rounded-lg border bg-background p-6">
  <ContourBackground tone="azure" />
  <h2>Northern Fairway</h2>
</section>
```

Give the container `relative isolate`: the effect is `absolute inset-0 -z-10`, and without `isolate` it disappears behind the container's own background. Content placed after it renders on top.

## Tone, intensity and speed

`tone` takes its ink from the theme: `neutral` (`--foreground`), `primary`, or a chart accent (`azure`, `saffron`, `lime`, `blue`); there is no red, the alarm colour. `intensity` sets the ink opacity (`low` 8 %, `medium` 16 %, `high` 32 %) so text keeps its contrast, and `speed` the cycle length (`slow` 60 s, `normal` 36 s, `fast` 18 s).

`ContourBackground` colours its isolines by elevation (`palette="map"`, the default); `palette="tone"` draws them in the `tone`, and `grid` adds a survey grid.

## Motion

`animate={false}` freezes an effect on its static frame; it also freezes under reduced motion, while scrolled out of view and while the tab is hidden, and is hidden in print and forced-colours mode.

<ComponentPreview name="background-static" />

`GridBackground`, `HexagonsBackground` and `TerrainGridBackground` take `interactive` to light the pattern up around the pointer as it moves over the parent element.

## Picking by name

`BackgroundEffect` renders an effect by name, for a settings screen where users choose their background. `backgroundEffects` maps names to components; `backgroundTones`, `backgroundIntensities` and `backgroundSpeeds` list the values of the shared props.

```tsx
import { BackgroundEffect, backgroundEffects } from "@tecton/react/tecton/background"

const names = Object.keys(backgroundEffects) // "seismic" | "contour" | …

<BackgroundEffect effect={preference} tone="azure" intensity="low" />
```

## Usage guidelines

### Use it when

- A large, otherwise plain surface needs texture: a hero, a sign-in page, an onboarding step, a dashboard header.
- The imagery is decoration — it says nothing a reader has to read, and losing it costs nothing.
- The surface belongs to this product, so an oil and gas motif reads as the domain rather than as clip art.

### Not for

- an interactive map, schematic or 3D view: use [Canvas](/docs/tecton/canvas)
- a placeholder shape while real content loads: use [Skeleton](/docs/components/skeleton)
- an empty state with a message and an action: use [Empty](/docs/components/empty)
- a picture of real data: use [ChartContainer](/docs/components/chart)

### Do

<DoList>

<Do>

Render the named effect (`ContourBackground`, `SeismicBackground`, …) as the first child of a `relative isolate overflow-hidden` container, with the content after it.

</Do>

<Do>

Pick the ink with `tone`, the weight with `intensity` and the cycle with `speed`; on busy screens stay at `intensity="low"`.

</Do>

<Do>

Let the effect decide when to move: it already freezes under `prefers-reduced-motion`, off screen and in a hidden tab, and hides itself in print and forced colours. `animate={false}` pins it to its static frame.

</Do>

<Do>

Choose an effect by name with `BackgroundEffect` and the `backgroundEffects`, `backgroundTones`, `backgroundIntensities` and `backgroundSpeeds` lists when the person picks their own.

</Do>

<Do>

Build a new effect on the shared `Background` layer so it inherits `--bg-ink`, the pausing and the print rules; do not reimplement the layer.

</Do>

</DoList>

### Don't

<Dont severity="HIGH" title="A gradient in className instead of an effect">

<Wrong>

```tsx
<section className="relative isolate rounded-lg border bg-gradient-to-br from-blue-500/20 to-transparent p-6">
  <h2 className="text-lg font-medium">Northern Fairway</h2>
</section>
```

</Wrong>

<Correct>

```tsx
<section className="relative isolate overflow-hidden rounded-lg border bg-background p-6">
  <ContourBackground tone="azure" intensity="low" />
  <h2 className="text-lg font-medium">Northern Fairway</h2>
</section>
```

</Correct>

`from-blue-500` is stock Tailwind and the palette is declared after `--color-*: initial`, so the gradient emits no CSS and the surface stays flat; an effect takes its ink from the theme through `tone` and flips with the mode on its own.

</Dont>

<Dont severity="HIGH" title="A background layer without relative isolate">

<Wrong>

```tsx
<Card>
  <SeismicBackground tone="primary" intensity="low" />
  <CardHeader><CardTitle>Survey 24-B</CardTitle></CardHeader>
</Card>
```

</Wrong>

<Correct>

```tsx
<Card className="relative isolate">
  <SeismicBackground tone="primary" intensity="low" />
  <CardHeader><CardTitle>Survey 24-B</CardTitle></CardHeader>
</Card>
```

</Correct>

The layer is `absolute inset-0 -z-10`: `Card` sets `bg-card` but neither `relative` nor `isolate`, so the effect positions itself against some ancestor further up and its negative z-index puts it behind the card's own background, where it is invisible.

</Dont>

<Dont severity="MEDIUM" title="The interactive prop on an effect that has none">

<Wrong>

```tsx
<div className="relative isolate overflow-hidden rounded-lg p-8">
  <SeismicBackground interactive tone="azure" />
  <p className="text-sm">Choose a project to open.</p>
</div>
```

</Wrong>

<Correct>

```tsx
<div className="relative isolate overflow-hidden rounded-lg p-8">
  <GridBackground interactive tone="azure" />
  <p className="text-sm">Choose a project to open.</p>
</div>
```

</Correct>

Only `GridBackground`, `HexagonsBackground` and `TerrainGridBackground` take `interactive`; on any other effect it is a type error that esbuild strips, the boolean is spread onto the layer `div` as a stray attribute, and the pointer reveal silently never happens.

</Dont>

{/* guidelines:end */}

## API Reference

### Shared props

Every effect renders an `aria-hidden`, `pointer-events: none` `div` and accepts its props plus:

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `tone` | `"neutral" \| "primary" \| "azure" \| "saffron" \| "lime" \| "blue"` | `"neutral"` | Ink colour, from the theme. |
| `intensity` | `"low" \| "medium" \| "high"` | `"medium"` | Ink opacity: 8 %, 16 % or 32 %. |
| `speed` | `"slow" \| "normal" \| "fast"` | `"normal"` | Cycle length: 60 s, 36 s or 18 s. |
| `animate` | `boolean` | `true` | Play the motion. |

### ContourBackground

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `palette` | `"map" \| "tone"` | `"map"` | Colour by elevation, or in the single `tone`. |
| `grid` | `boolean` | `false` | Draw a survey grid under the isolines. |

### GridBackground, HexagonsBackground, TerrainGridBackground

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `interactive` | `boolean` | `false` | Reveal the pattern around the pointer over the parent element. |

### BackgroundEffect

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `effect` | `BackgroundEffectName` | - | Key of `backgroundEffects`. The other props are the chosen effect's. |

### Background

The layer the effects are built on, for composing your own effect with the same positioning, pausing and theme variables (`--bg-ink`, `--bg-ink-soft`, `--bg-ink-strong`).
