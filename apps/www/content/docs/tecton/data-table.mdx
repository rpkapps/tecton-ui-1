## Usage

```tsx
import {
  DataTable,
  createDataTableColumns,
  type RowSelectionState,
} from "@tecton/react/tecton/data-table"
```

```tsx
type Well = { name: string; field: string; td: number }

const helper = createDataTableColumns<Well>()
const columns = helper.columns([
  helper.accessor("name", { header: "Well" }),
  helper.accessor("field", { header: "Field" }),
  helper.accessor("td", { header: "TD (m)" }),
])

<DataTable label="Wells" columns={columns} data={wells} />
```

<Callout title="A component, not a recipe">
  The shadcn [Data Table](/docs/components/data-table) is a guide for composing `Table` with TanStack Table yourself. Tecton's emphasised header, alternating rows, densities and small-screen layout cannot be expressed through variables, so `DataTable` packages that composition (TanStack Table v9 feature API) as one component. The plain [Table](/docs/components/table) is unchanged.
</Callout>

## Selection

Set `enableSelection` for a leading checkbox column and multi-row selection. Provide `getRowId` for stable ids and listen with `onRowSelectionChange`.

## Density

Use `density="sm"` for compact rows; `alternateRows={false}` turns off the alternating shading.

<ComponentPreview name="data-table-density" />

## Pagination

Pass `pageSize` to paginate. The footer shows the page size select, the page count and navigation; `footer` adds content on the left.

<ComponentPreview name="data-table-pagination" />

## Small screen

Set `smallScreen` to stack each row's cells with their column label below the `md` breakpoint. Column labels come from string `header`s.

## API Reference

### DataTable

Renders a TanStack table with the shadcn `Table` primitives. Column headers are sortable by default (`enableSorting: false` in a column definition turns it off).

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `columns` | `DataTableColumnDef<TData>[]` | - | Column definitions from `createDataTableColumns<TData>()`. |
| `data` | `TData[]` | - | Row data. |
| `label` | `string` | "Data table" | Accessible name of the grid. |
| `density` | `"md" \| "sm"` | "md" | Row height 44 / 36 px. |
| `alternateRows` | `boolean` | true | Alternating row shading. |
| `enableSelection` | `boolean` | false | Checkbox column and multi-selection. |
| `pageSize` | `number` | - | Rows per page; omit to disable pagination. |
| `pageSizeOptions` | `number[]` | [10, 25, 50, 100] | Choices in the page size select. |
| `smallScreen` | `boolean` | false | Stack cells on narrow viewports. |
| `emptyMessage` | `ReactNode` | "No results." | Content when there are no rows. |
| `footer` | `ReactNode` | - | Extra footer content (left). |
| `getRowId` | `(row, index) => string` | - | Stable row ids. |
| `onRowSelectionChange` | `(selection: RowSelectionState) => void` | - | Selection listener. |
| `onSortingChange` | `(sorting: SortingState) => void` | - | Sorting listener. |
| `onRowAction` | `(rowId, row) => void` | - | Double click / Enter on a row. |

### createDataTableColumns

Typed `createColumnHelper` bound to the DataTable feature set. Use `helper.accessor`, `helper.display` and `helper.columns`.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `TData` | `generic` | - | Row type. |
