## Usage

```tsx
import { Link } from "@tecton/react/tecton/link"
```

```tsx
<Link href="/wells/34-10-A-12" variant="primary">
  34/10-A-12
</Link>
```

<Callout>
  `Button` has a `link` variant for buttons that look like links; `Link` is the opposite: a real anchor for navigation. Use `buttonVariants` on an `<a>` when a link should look like a button.
</Callout>

## Variants

Use the `variant` prop. `subtle` is always underlined, the others underline on hover.

## API Reference

### Link

An anchor with the Tecton link styles and focus ring. Accepts `href`, `routerOptions`, `isDisabled` and `onPress`.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `variant` | `"default" \| "primary" \| "muted" \| "subtle"` | "default" | Colour and underline behaviour. |
| `size` | `"inherit" \| "sm" \| "md" \| "lg"` | "inherit" | Font size. |
| `isExternal` | `boolean` | false | Opens in a new tab and shows an icon. |
| `isDisabled` | `boolean` | false | Disables the link. |
