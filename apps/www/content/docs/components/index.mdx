Every component on these pages ships in `@tecton/react`, themed with the Tecton design
tokens and accessible out of the box: keyboard behaviour, focus management, selection
and ARIA semantics are part of the component, not something to add on top.

Several components carry variants that exist because Tecton needs them — the status
colours and appearances on `Alert` and `Badge`, `emphasis` on `Separator`, the outline /
filled / text surfaces on `Input`, `Textarea` and `Select`. Each page documents those in
its own section.

<Callout title="One import">
  Every component is imported from the package:
  `import { Button } from "@tecton/react/components/button"`. There is nothing to install
  per component; see [Installation](/docs/installation) for adding the package to an
  application.
</Callout>

## Primitives

A few compositions need more than a component: a context menu needs a press target around
your own markup, a searchable select needs a filter, and controlled selection or range
props need their types named. Those come from `@tecton/react/primitives`:

```tsx
import { Autocomplete, Pressable, useFilter } from "@tecton/react/primitives"
import type { DateRange, Key, Selection } from "@tecton/react/primitives"
```

| Export | Used with |
| --- | --- |
| `Pressable` | The child of a [ContextMenuTrigger](/docs/components/context-menu) — makes arbitrary markup a press target |
| `Autocomplete`, `useFilter` | Filtering the list of a [Select](/docs/components/select#searchable) or [Command](/docs/components/command) |
| `Key` | The identity of a collection item — `SelectItem`, `Chip`, `TreeViewItem`… |
| `Selection` | The controlled selection of a multi-select collection: a `Set` of keys, or `"all"` |
| `DateRange` | The controlled value of a range [Calendar](/docs/components/calendar) or [Date Picker](/docs/components/date-picker) |

Everything a Tecton composition needs is in the package. If you find yourself reaching for
another library to make a component work, that is a gap in Tecton — raise it rather than
importing around it.
